```
[10 万条 Amazon Electronics 评论]
   → [RLCA 两阶段标注：规则初筛 1502 → LLM 复核 → 三星补漏 479 → 置信度分层]

   → [Agent 报告(md/excel, zh/en) / Gradio Demo(三页) / FastAPI / 在线创空间]
```

## 三、核心数字（详见 `03_metrics_and_caveats.md`）

**冻结口径（val_v2：20,000 条 / 251 正例）**
- 二分类：F1 **0.6871** @ 阈值 **0.9744**；F1@0.5 = 0.6241；5 折 CV **0.6234 ± 0.0240**
- AUC-PR **0.7191**；Welch t 检验 **p = 0.000932**（vs SVM 0.497 ± 0.017、LR 0.410 ± 0.022、dummy 0.025）
- 混淆矩阵（0.9744）：TP 179 / FP 91 / FN 72 / TN 19,658（GPU 重跑 TP 178 / FN 73，已调和）
- 多标签五类：宏 F1 **0.6481**（低音 0.79 / 清晰度 0.77 / 杂音 0.84 / 音量 0.84 / **高音 0.00**）
- 标注侧：规则精度 **51.8%** → LLM 复核后人工抽查 **78%**（n=50，Wilson CI 64.8%-87.2%）；三星评论漏检率 **41.5%**（CI 34.9%-48.4%）

**1,000 条子集口径（LLM 对照，不可与冻结口径混用）**
- 本地小模型 0.8260；deepseek-chat 零样本 0.9400 / 5-shot 0.8728 / 复核 0.8462
- qwen3.7-plus 零样本 0.9149 / 5-shot 0.8937 / 复核 0.8661

**工程与验证数字**
- 吞吐：GPU 1.763 秒 / CPU 28.443 秒（每 1,000 条，含多标签）；线上批量 100 条 15.1 秒
- 校准：十箱 ECE 0.0122，但决策区间过度自信（[0.9,1.0) 置信 0.975 vs 实际正例率 0.555）
- 长度分桶：≤64 token 0.708 / 65-128 token 0.749 / **>128 token（截断桶）0.565**
- 错误构成：FP 91（"其他问题"占 54.9%）、FN 73（委婉+双面占 58.9%）；标注噪声 **9.1%**（人工终审 15/16，CI 5.6%-14.5%）
- 复合差评（命中 ≥2 类）：**23.5%**（1 类 961 / 2 类 252 / 3 类 40 / 4 类 4）
