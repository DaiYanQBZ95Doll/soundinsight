# 07 术语表（AI 助手用）

| 术语 | 含义 |
|---|---|
| **RLCA** | Rule-LLM Cascade Annotation，本项目自研两阶段标注框架：规则初筛（关键词边界匹配 + 星级阈值）→ LLM 全量复核 → 三星评论召回补漏 → 置信度分层 |
| **冻结口径** | 以 `val_v2.csv`（20,000 条 / 251 正例）为验证集、基于 1,257 条正例训练的全部实验数字；对外一律引用这一套（权威源 `results_summary.md`） |
| **1,000 条子集口径** | LLM 对照专用：val_v2 正例全集 251 + 749 条负例采样（seed=42）；FP 被稀释约 24 倍，**不可与冻结口径比较** |
| **正例口径演进** | 1,257（冻结）→ 1,288（高音补捞 +31）→ 1,280（中置信剔除 8）；引用时必须注明属于哪个阶段 |
| **中置信层** | 三星补漏样本中 LLM 置信度 ∈ [0.60, 0.80) 的 8 条；人工复核仅 3/8 通过 → 全部剔除 |
| **三星漏检率 41.5%** | 三星评论中实为音质差评的比例（n=200，Wilson 95% CI 34.9%-48.4%），是规则与通用情感工具的主要盲区 |
| **弱标注精度 51.8%** | 规则初筛命中的 1,502 条候选中，经 LLM 复核确认的比例 |
| **复合差评** | 一条评论同时命中 ≥2 个问题类别；实测占差评的 23.5%（1 类 961 / 2 类 252 / 3 类 40 / 4 类 4） |
| **五类归因** | 低音 / 清晰度 / 杂音 / 音量 / 高音；独立 sigmoid 头，宏 F1 0.6481（高音 0.00） |
| **阈值 0.9744** | 验证集上 F1 最优的二分类决策阈值（对外显示口径 0.97） |
| **ECE** | Expected Calibration Error，十箱校准误差；本项目 0.0122，但被 97% 落在 [0,0.1) 的样本稀释，决策区间实际过度自信 |
| **AUC-PR** | PR 曲线下面积，本项目 0.7191 |
| **压缩比/截断桶** | >128 token 的评论在 max_len=128 下被截断，占 18.6%，F1 0.565 / 召回 54.4% |
| **Wilson CI** | 小样本比例的二项置信区间（本项目用于 78%、41.5%、9.1% 等比例） |
| **同源标签红利** | 用 deepseek-chat 零样本去考它自己参与制作的标签时产生的自我一致性优势；qwen3.7-plus 无此红利 |
| **显式拒绝（is_unsupported）** | 非英文评论不参与判定并明确标记，避免"静默判为正常"的漏报风险 |
| **PSI** | Population Stability Index，漂移监控指标（方案阈值 0.2，见 `docs/drift_plan.md`） |
| **其他材料包** | `更新世界的锋芒_SoundInsight_其他材料.zip`：46 份验证报告/审计/图表/人工复核原始表/复算脚本 |
| **封包声明** | `docs/D13_seal_declaration.md`：封包时点的完成事项、校验值、偏差清单与审核清单 |
| **审计** | `check_doc_numbers.py` 生成的 143 项检查（数字同源 + 违禁 claim + 三口径一致性 + 模板九章格式） |
