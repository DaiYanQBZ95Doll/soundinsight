## 一、项目是什么（30 秒）

**SoundInsight——蓝牙耳机音质差评智能归因系统**（AI+跨境黑客松巅峰赛·复赛，AI 市场洞察赛道，团队"更新世界的锋芒"）。

链路：`10 万条 Amazon 真实评论 → RLCA 两阶段标注 → DistilBERT 二分类 + 五类多标签归因 → Agent 报告 / Gradio Demo / FastAPI / 在线创空间`

解决的痛点：跨境耳机卖家的英文差评量大、音质问题藏得深（实测三星评论中 41.5% 实为音质差评），通用情感工具只分正负不做归因。

## 三、三条最重要的禁忌（改动前必读）

1. **不要改冻结数字**：`results_summary.md` 是唯一权威源；模型权重、`val_v2.csv`、训练脚本一律不动。
2. **不要混用口径**：冻结口径（val_v2 20,000 条）、1,000 条子集口径（LLM 对照）、工程数字（吞吐/校准/长度分桶）在文档中分区标注，**不可互相替代**。
3. **不要编造**：本项目明确未开展用户验证、未做多语言支持；不利结论（校准过度自信、标注噪声 9.1%、高音 F1=0）均已如实写入文档，不要"优化"它们。
