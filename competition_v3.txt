## 二、参赛信息

参赛场景：AI市场洞察

方案名称：SoundInsight

一句话定义：为跨境电商耳机卖家提供音质差评自动识别与五类问题归因的一站式洞察工具，将人工数小时的差评梳理压缩至分钟级。

## 三、业务价值与市场分析

### 3.1 目标用户与业务痛点

目标用户：跨境电商平台耳机类目中小卖家（团队小于10人，无专职数据分析师）

核心痛点：

1. 差评数量大：日均 50-200 条，人工翻看耗时
2. 语言杂：英文为主，夹杂西班牙语、日语等
3. 音质问题隐蔽：藏在长文本里，三星评论中 41.5% 实为音质差评（本项目实测发现）
4. 改进滞后：无法系统归类问题，产品迭代凭经验

### 3.2 应用场景与使用流程

场景一（选品）：产品经理输入竞品 ASIN，生成音质差评对比报告

场景二（优化）：运营上传自家评论 CSV，一键生成问题分布与整改建议

场景三（迭代）：研发对比改版前后报告，验证改进效果

使用流程：上传 CSV → 3 秒分析 → 查看报告（含优先级排序）→ 导出 Excel

### 3.3 商业价值与预期效果

### 3.4 市场前景与落地可行性

市场规模：全球耳机市场 280 亿美元（Statista 2025），亚马逊耳机类目年评论量超 5000 万条

## 四、产品功能与使用说明

### 4.1 产品简介

SoundInsight 是一款面向跨境电商耳机卖家的音质差评智能归因系统。基于 DistilBERT 微调模型，自动识别评论中的音质负面反馈，并归因至低音、清晰度、杂音、音量、高音五类问题，输出可执行的洞察报告。

### 4.2 核心功能清单

1. 单条评论判定：输入评论文本，输出音质负面概率与问题类别
2. 批量 CSV 分析：上传评论文件，生成差评率、问题分布统计
3. 一键洞察 Agent：命令行输入 python soundinsight_agent.py --csv 文件.csv，自动生成完整报告
4. 多标签归因：同时识别多种音质问题（如低音+杂音复合差评）

### 4.3 使用说明

安装：pip install -r requirements.txt

启动 Demo：python demo_sound_v2.py

启动 Agent：python soundinsight_agent.py --csv test.csv

截图：单条判定页、批量分析页、Agent 报告页（各 1 张）

## 五、技术架构及调用模型说明

### 5.1 系统架构图

见 architecture.png，文字链路为：

[Amazon评论数据 10万条] → [RLCA两阶段标注] → [DistilBERT二分类+多标签] → [Agent报告 / Gradio Demo]

标注层细节：规则初筛（关键词匹配） + LLM复核（qwen3.7-plus）

模型层细节：1:10欠采样、阈值扫描、5折CV验证

### 5.2 调用的阿里云百炼模型

| 模型标识 | 用途 | 调用方式 |
|---------|------|---------|
| qwen3.7-plus | 两阶段标注中的LLM复核 | 阿里云Token Plan API |
| deepseek-v4-pro | 基线验证与备选方案测试 | 阿里云Token Plan API |

### 5.3 技术组件说明

前端：Gradio（单条判定 + 批量分析界面）

后端：Python + PyTorch + Transformers

模型：DistilBERT-base-uncased（66M参数，ModelScope镜像）

数据：McAuleyLab AmazonElectronics 2023（10万条评论）

标注：RLCA两阶段流水线（规则初筛 + LLM全量复核）

部署：本地GPU推理（RTX 4060），支持一键启动

## 六、项目开发及阶段成果说明

### 6.1 开发过程

D1：数据扩充（10万条）、两阶段标注（1257正例）、基线对比

D2：消融实验（3组）、统计验证（学习曲线/PR曲线/t-test）、数据提纯

核心统计口径（冻结，详见 competition_v4.md）：5折CV平均F1 0.6234±0.024；val_v2 上 Precision 47.9%、Recall 89.6%、F1 0.687、AUC-PR 0.7191、t检验 p=0.000932；最优阈值 0.9744；基线F1：SVM 0.497 / LR 0.410 / dummy 0.025；弱标注精度 51.8%；三星补漏人工抽查 78%。

### 6.2 核心挑战与解决方案

| 挑战 | 解决方案 | 验证结果 |
|------|---------|---------|
| 正样本极度稀缺（13条） | RLCA两阶段标注 | 扩充至1257条 |
| 类别不平衡（1.3%） | 1:10欠采样+阈值扫描 | F1从0.37→0.69 |
| 委婉表达漏检 | LLM复核三星评论 | 补漏479条 |
| GPU显存受限（8GB） | 选用DistilBERT | batch16稳定训练 |
| 高音样本不足 | 关键词补捞+LLM复核 | 确认 66 条高音正例，高音标签从 84 增至 124 条（净增 40） |

### 6.3 后续迭代计划

时序分析（已完成）：10万条评论时间戳全部恢复，2021-2023 月度差评率趋势图已生成；跨年份分桶验证（时间戳覆盖 19,996/20,000 条验证集）未发现模型随时间衰减

竞品对标：多ASIN对比雷达图

多语言适配：XLM-R基座替换

持续学习：在线模型更新机制
