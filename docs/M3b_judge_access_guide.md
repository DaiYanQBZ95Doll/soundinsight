## 二、首次访问提示

- **冷启动**：免费 CPU 空间在闲置后首次打开**可能需要数十秒**（页面会先显示加载状态），请稍候或刷新一次。
  （**待实测**：记录一次真实冷启动耗时，写在此处。）
- **批量上传限制**：设计上支持 100 条样例（`sample_reviews_100.csv`）；更大批量建议本地运行 Agent
  （`python soundinsight_agent.py --csv your.csv`）。（**待实测**：在线页面的单文件大小/条数上限。）
- **输出语言**：中文/英文可切换；**非英文评论会被显式跳过并计数**（不是静默丢弃）。
- **无需账号**；若页面提示登录，说明触发了平台限流，请改用路径 2 或 3。

## 三、结果怎么读（30 秒版）

1. 报告六节：总体概况／问题分布／典型案例／行动建议／验证指标／**置信度档位与建议动作**；
2. **置信度三档**：高（≥调优档，可直接进整改评审）／中（0.5–调优档，先抽查）／低（<0.5，仅趋势观察）；
3. 每条结论都可追溯到模型输出与阈值档——**这是本项目的核心差异点（可审计）**。

## 四、已知边界（评委可能遇到的"看起来不对"）

| 现象 | 原因（已披露） |
|---|---|
| 长评论（>128 token）偶有漏报 | 长文本桶召回 **68.3%**（验收线 70%，未达）；机制为"子片段信号被整篇平均" |
| "高音"类很少被识别 | 该类 F1 **0.5333**（v1 为 0），是最弱类别，已披露 |
| 非音频品类（如配件）偶有误报 | 跨品类误报率 0.62%（含 3 条高置信误报）；建议配合关键词约束使用 |
| 概率"看起来偏低" | v2 已做温度缩放校准；未校准前档位仅供排序 |

## 五、给评委的一句话

> 我们不掩饰短板：**未达标的验收线与最弱类别都写在主文档附录 B**；
> 想验证数字，请打开 `其他材料.zip` 里的 `number_audit.md` 与 `v2/` 证据目录——**每个数字都能复算**。
