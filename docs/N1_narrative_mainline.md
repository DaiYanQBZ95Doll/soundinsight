## 二、四段主线（每段附证据指针）

### 段 1｜问题：卖家的"音质差评"读不出可执行结论

- 跨境蓝牙耳机卖家的差评里，音质类投诉藏在长文本中，通用情感工具只分正负、不归因；人工翻 1,000 条约需 8 小时
  （**成本对照为假设口径**：人工 8 h、30 元/h，见 `competition_v4.md` §三 3.3；须在材料中标明为假设）。
- 本项目自测的量化入口：**三星评论中 41.5%（n=200，95% CI 34.9–48.4%，Wilson）实为音质差评**被规则漏检
  （`competition_v4.md`:169）。
- 行业侧旁证（**二手来源，须标注**）：AMZ123 转载 Pangolinfo 抓取分析（2026-05）称 3 款 Amazon US 热销耳机
  151,295 条评论中 67% 差评集中在可靠性/连接/续航方向，音质差评最少
  （`docs/external_sources_register.md` §一 S1：**厂商内容、方法概要、不可复现**，引用须注明）。

### 段 2｜做法：两阶段标注 + 二分类 + 五类归因，全部本地可复算

- **RLCA 两阶段标注**：规则初筛召回候选 → LLM 逐条复核去伪 → 三星补漏；当前工作集正例 **1,280** 条
  （口径演进 1,257`[v1]` → 1,288 → 1,280；`docs/gap_and_roadmap_inventory.md` A2-14）。
- **二分类**：DistilBERT；v1 主指标 **F1@调优(0.9744) = 0.6871**`[v1]`、高召回档 **F1@0.5 = 0.6241**`[v1]`；**当前代 v2（`val_v3_test`，阈值取自 `val_v3_tune`）F1@调优(0.6) = 0.7220`[v2]`、PR-AUC 0.7811`[v2]`**
  （`results_summary.md`:45–53；两档并列时**必须标档**，审计有机械检查）。
- **五类归因**：低音／清晰度／杂音／音量／高音；v1 宏 F1 **0.6481**`[v1]`、高音类为 **0**（零触发）（`results_summary.md`:59–66）；**v2 逐类阈值后宏 F1 0.8273`[v2]`、高音 0.5333`[v2]`**（`v2/w2_perclass_thresholds.md`）。
- **产品形态**：Agent 报告（含行动建议与复评周期）+ Gradio Demo + FastAPI + 在线创空间
  （`competition_v4.md` §四 4.1–4.3）。

### 段 3｜为什么可信：把"可审计"做成了系统能力（**本项目的差异点**）

- **数字审计**：`check_doc_numbers.py` 现有 **全部检查项（当时 211 项；以 `number_audit.md` 为准）机械检查 / 0 FAIL**（含决赛主文档数字核对、产品代码健康、关键文件完整性），覆盖口径配对（阈值档）、
  代际混用、提交包冻结、决赛模板合规、v2 产物、**否定性状态断言**（`number_audit.md`）；
- **检查会拒绝坏输入**：`test_audit_checks.py` **15 项负向用例全通过**（证明不是"只报 PASS"）；
- **仓库卫生**：`scan_repo_hygiene.py` → **密钥 0（含 git 历史）**、隐私项逐条说明、废弃 claim 分类
  （`docs/repo_hygiene_scan.md`）；
- **外部数字三档裁定**：`docs/external_sources_register.md` 明确"可引用／核到但不可引用／未核实"，
  并写入判断纪律：**"未能证实" ≠ "已被证伪"**；
- **三方互审留痕**：执行方错 3 次、质检方 1 次、外部顾问过期结论 2 次，**全部更正并入档**
  （`docs/final_project_review_and_execution_plan.md` §七）——机制对三方同时生效。

## 三、口径纪律（写作时不得违反）

1. 任何 F1／精确率／召回率必须带阈值档（`@调优(0.9744)` 或 `@0.5`）；两档不可并排而不标档；
2. 两代数字必须标 `[v1]`／`[v2]`；**v1（val_v2）与 v2（留出划分）是不同样本集，不可直比**；
3. 外部数字按 `docs/external_sources_register.md` 三档使用；与本项目实测数字**不得并排成同一口径**；
4. 成本假设（8 小时、30 元/小时）须写明为**假设**；
5. 未修短板不得在叙事中消失或改写成已修（采纳闸门第 (6) 条）。
