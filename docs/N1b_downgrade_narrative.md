## 二、骨架：每条边界走同一套四段式

统一格式：**① 发现（怎么察觉）→ ② 量化（分母与比例）→ ③ 处理（做了什么）→ ④ 前后对比（结果或"未达"的如实结论）**

### 边界 1｜长文本截断
- ① 发现：分桶评估显示 >128 token 桶指标显著低于短文本桶；
- ② 量化：该桶占 val_v3_test 的 **19.3%**（1,934/10,000）；截断推理召回 **51.2%**；token 分布显示超长部分 **39.3% 超过 256 token**（P99=694）；
- ③ 处理：四变体对比（truncate@128／@256／segment 切窗／@512）；
- ④ 前后对比：**待填**（`docs/w1_longtext_variants.md` 已有三变体，512 训练中）。
  **如实结论模板**：若最终召回落在 68–83% 而验收线为 70%，写"**切窗聚合可达 82.9% 召回但同档 F1 仅 0.42；兼顾 F1 时召回 68.3%，未达 70% 验收线**"。

### 边界 2｜高音类别零触发
- ① 发现：逐类指标出现 **F1 = 0**（不是低，是零）；
- ② 量化：该类样本 84 条，模型最高概率 **0.3332 < 0.5**，TP=0/FP=0/FN=13；关键词漏检 **62.6%**；该类别正例占 124/1,280；漏报类别分布中高音仅 2 条；
- ③ 处理：方案 C（标签重定义 + 重训）已选定，W3 执行；
- ④ 前后对比：**待填**（W3 结果）。

### 边界 3｜阈值选择偏差（v1 从未披露）
- ① 发现：审计定位到 `distilbert_cv.py`:90 **在同一折上选阈值并报数**；
- ② 量化：v1 的 0.6871`[v1]` 与 CV 0.6234`[v1]` 因此含**乐观偏置**，此前从未披露；
- ③ 处理：v2 起**阈值只在 `val_v3_tune` 上选、指标只在 `val_v3_test` 上报**（W6 协议 + 机械检查）；
- ④ 前后对比：**待填**（W2/W5）。

### 边界 4｜评测泄漏（本轮新发现，可作为"测绘能力"的最强例证）
- ① 发现：一次 max_len=256 训练在 val_v2 上得到 **F1@0.5 = 0.9126**，**高于教师上限**——不合理的数字触发自查；
- ② 量化：val_v2 与当前训练划分重叠 **15,891/20,000（79.5%）**，含正例 **198/251（78.9%）**；
- ③ 处理：改为从**当前标签集的留出划分**取 val_v3（tune/test 各 10,000）；manifest 内置泄漏核查值；
- ④ 前后对比：同模型整体 F1@0.5 **0.9126 → 0.7206**（**降下来才是真的**）。
  **定版答法**：v1 的数字在其**当时一致**的划分上仍然有效；但用当前文件**无法复现**该划分（行序已变），
  故 v1 只能由冻结模型 + 冻结 `val_v2` 复现，且**两代不可直比**。

### 边界 5｜字段缺失导致的能力缺口（已补齐）
- ① 发现：`electronics_expanded.csv` 只保留 text/rating/timestamp，型号级与鲁棒性分析无从下手；
- ② 量化：原始前缀中 `asin/parent_asin/verified_purchase/user_id/helpful_vote/title` **非空率 100%**；
- ③ 处理：P0-3 复现同一套过滤后按 **text 序列**对齐恢复（100k/100k 一致）；
- ④ 前后对比：解锁三项能力——型号级聚合（711 个型号达 ≥10 条门槛）、
  对抗性三项（未验证购买误报 0.58% vs 已验证 0.43%）、星级分层（2★ 差评率 7.97% 最高）。

### 边界 6｜校准形态与极端阈值
- ① 发现：最优阈值 **0.9744** 贴近 1.0 才最优；决策区间 [0.9,1.0) 置信 0.975 对实际 0.555（偏差 −0.42）；
- ② 量化：整体 ECE 0.0122 被 97% 低分箱稀释；
- ③ 处理：W7 校准（温度缩放／Platt，**只在 tune 上拟合**）；
- ④ 前后对比：**待填**（W7）。

### 边界 7｜不可修与不可执行（如实分栏）
- 标注噪声 **9.1%**（CI 5.6–14.5%）——需第二标注者，缺；
- 共享教师偏差——需全人工金标准，缺；
- 真实用户验证——**无渠道，客观不可执行**（记录原因，不只记结果）；
- 非英文覆盖为 0%（显式拒绝并计数）。
