## 一、一句话

> **我们把耳机差评做成了"可审计的音质归因系统"——不只是给结论，还给结论的可复算证据链。**

## 二、四段主线（v2 数字版）

### 段 1｜问题：音质差评读不出可执行结论

- 通用情感工具只分正负、不归因；人工翻 1,000 条约 8 小时（**成本对照为假设口径**：8 h × 30 元/h）。
- 本项目自测入口：**三星评论中 41.5% 实为音质差评**（n=200，95% CI 34.9–48.4%，Wilson）被关键词规则漏检。
- 四条可执行结论的落点：问题分布（占比+优先级）、典型案例（含五类归因概率）、行动建议（带复评周期）、
  **每条结论带置信度档位与建议动作**（`docs/w17_confidence_actions.md`）。
- 行业旁证（**二手来源，引用须标注**）：AMZ123 转载 Pangolinfo（2026-05，厂商内容、不可复现），
  见 `docs/external_sources_register.md` S1。

### 段 2｜做法：两阶段标注 + 二分类 + 五类归因，全本地可复算

- **RLCA 两阶段标注**：规则初筛 → LLM 逐条复核去伪 → 三星/四五星补漏；当前正例 **1,280**
  （口径演进 1,257`[v1]` → 1,288 → 1,280）。
- **二分类（v2，`val_v3_test` n=10,000／正例 128；阈值取自 `val_v3_tune`）**：
  **F1@调优(0.6) = 0.7220`[v2]`**（P 77.0%／R 68.0%）、高召回档 **F1@0.5 = 0.7206`[v2]`**、
  **PR-AUC = 0.7811`[v2]`**（`v2/w5_final.md`）。
- **五类归因（逐类阈值）**：宏 F1 **0.8273`[v2]`**；高音类 F1 **0.5333`[v2]`**（v1 为 0，属零触发）
  （`v2/w2_perclass_thresholds.md`）。
- **概率校准**：温度缩放 T=1.59（只在调参划分上拟合）；决策区间 ≥0.9 偏差 −0.172 → **−0.060`[v2]`**；
  抗稀释 ECE（p≥0.5）0.222 → 0.117`[v2]`（`v2/w7_calibration.md`）。
- **产品形态**：Agent 六节报告 + Gradio 三页 Demo + FastAPI + 在线创空间。
- **v2 新增能力（字段恢复解锁）**：型号级差评率聚合（711 个 ASIN 达 ≥10 条门槛，Top-20 区间
  14.3%–30.0% 对全局 1.28%）、月度趋势与告警阈值标定（≥3pp）、对抗性三项
  （已验证购买过滤 F1 0.6871→0.7034`[v1 模型]`；同用户去重后差评率 1.28%→1.28%；helpful_vote 加权 Top-10 重合 7/10）。

### 段 3｜为什么可信：把"可审计"做成了系统能力（**差异点**）

- **数字审计**：`check_doc_numbers.py` **198 项检查 / 0 FAIL`[v2 时点]`**，覆盖口径配对（阈值档）、
  代际混用、提交包冻结（红线 9，双向哈希）、决赛模板合规、v2 可核验产物、否定性状态断言、
  跨材料口径一致性（M0b）、**关键文件完整性（防脚本化截断）**。
- **检查会拒绝坏输入**：`test_audit_checks.py` **15 项负向用例全通过**（证明不是"只报 PASS"）。
- **v2 产物可核验**：权重 SHA256 + 阈值文件 + 训练命令 + 4 个评估产物登记（`v2/v2_artifacts.json`），
  审计机械校验哈希；权重不入库、按需复算。
- **卫生**：`scan_repo_hygiene.py` → **密钥 0（含 git 历史）**、隐私项逐条说明（`docs/repo_hygiene_scan.md`）；
  预提交守卫拦截凭据与超大文件。
- **外部数字三档裁定**：可引用／核到但不可引用／未核实，并写入纪律：**"未能证实" ≠ "已被证伪"**。
- **三方互审留痕**：执行方、质检方、外部顾问的错误全部更正入档（`docs/final_project_review_and_execution_plan.md` §七）。

## 三、三句话收尾（可直接用于路演与文档结尾）

1. **我们的指标不是"刷"出来的，是"审计"出来的**——两代口径、阈值档、样本集全部可追溯到文件。
2. **我们的短板是主动写的**——长文本 68.3% 未达线、高音 0.53、噪声 9.1%、无真实用户验证，都在附录里。
3. **我们的下一步是可验证的**——切片级打分与学习式聚合、跨品类迁移实证、W4 四五星复核（凭证到位即可跑）。
