# N5 答辩口径卡（事实底稿 · 供质检方定稿）

> **性质**：执行方按口径纪律整理的**事实底稿**；正式口径卡由质检方起草（D11 分工），决策方定稿。
> **用法**：每个问题给出"**定版答法**"，括号内为可点开的仓库证据；**答法中的数字必须带代际与阈值档**。

## B. 方法学类（最容易被追问，也最能加分）

| # | 问题 | 定版答法 | 证据 |
|---|---|---|---|
| B1 | 你们怎么保证标注可靠？ | "两阶段：规则初筛 → LLM 逐条复核去伪 → 三星/四五星补漏。弱标注精度 51.8% 经复核清洗到人工抽查 **78%**；剩余噪声 **9.1%**（Wilson CI 5.6–14.5%，人工终审 15/16）。**没有第二标注者**，所以算不了 κ——这是已披露的短板。" | `error_taxonomy.md`、`human_review_*.csv` |
| B2 | 训练和验证标签同源，算不算自证？ | "算，我们把它写成'**共享教师偏差**'并披露：训练与验证标签均由同一 LLM 复核，没有全人工金标准。我们做的是把偏差**量化**，不是否认它。" | `competition_v4.md` 局限章节 |
| B3 | v1 的阈值是不是在同一验证集上选的？ | "是，这是**乐观偏置**——v1 从未披露，我们在本轮**首次披露**，并让 v2 起走 tune/test 分离；审计有机械检查防止回退。" | `docs/e2_erratum.md` §3 |
| B4 | 旧验证集为什么不能再用？ | "标签文件被重建后行序改变，旧验证集与当前训练划分**重叠 79.5%**（正例 78.9%）——在它上面评估会因记忆虚高（实测 0.9126，**该数字作废**）。**v1 的 0.6871 仍然有效**（当时划分一致），只是**无法由当前文件复现**。" | `docs/e2_erratum.md` §4 |
| B5 | 你们的数字会不会写错？ | "我们做了**数字审计工具链**：全部检查项（当时 198 项；以 `number_audit.md` 为准）机械检查覆盖口径配对、代际混用、模板合规、产物哈希、跨材料一致性与文件完整性；另有 **15 项负向自测**证明检查会拒绝坏输入。" | `number_audit.md`、`test_audit_checks.py` |
