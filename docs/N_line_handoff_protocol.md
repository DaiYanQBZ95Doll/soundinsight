## 一、触发条件

同时满足即触发：

1. **W15（型号级聚合）与 W16（星级分层一致性）已产出素材**（N1/N2 的量化支撑）；
2. 或**任何 W 线包产出了可用于叙事的实测数字**（截断修复前后对比、高音处理结果、校准偏差、对抗性三项等）；
3. 此时执行方在仓库写入 **`docs/N_line_brief.md`**（格式见 §三），并在 `PROGRESS_SYNC.md` 待办中标记"待总线取件"。

**不触发的情形**：数字未冻结（T-3 前）时**可以**起草框架（N1/N1b/N4 的骨架不依赖新数字），但**含数字的段落一律等 T-3 后**再进入 brief（避免总线来回一次后又因数字变动返工）。

## 二、链路与角色

| 环节 | 承担方 | 动作 |
|---|---|---|
| ① 写 brief | 执行方 | 在 `docs/N_line_brief.md` 写入任务编号、目标一句话、DoD（照抄冻结清单）、**证据指针清单**、口径约束 |
| ② 取件与转发 | 决策方（总线） | 把 brief 全文 + 指针指向的**关键段落原文**贴给外部顾问 |
| ③ 产出 | 外部顾问（桌面端） | 纯文本产出：**N1 一页主线稿 + N4 论证页**（必要时附 N1b 降级版骨架） |
| ④ 回传 | 决策方（总线） | 把产出原文贴回执行方 |
| ⑤ 落库 | 执行方 | 合并进仓库 → 过 `M0b` 跨材料口径审计（逐字一致 + grep 零残留）→ 标注"**外部顾问起草 / 决策方定稿**" → 必要时升版清单 |

**往返预算**：2 个来回；总线（决策方）累计约 20 分钟。**返工主要来自 brief 里指针不准或口径未写清**，故 §三/§四 为强制字段。

## 四、口径约束（brief 必附，防止顾问返工）

1. **阈值档**：任何 F1 / 精确率 / 召回率必须带 `@调优(0.9744)` 或 `@0.5`；两档不可并排而不标档；
2. **代际**：`[v1]`＝复赛已提交口径，`[v2]`＝决赛口径（尚未产生）；两代并排必须各自标注；
3. **外部数字**：只能按 `docs/external_sources_register.md` 的三档使用——S2 可引、S1 须标注"厂商内容、方法概要、不可复现"、S3 不得作为行业事实；**不得**把外部二手数字与本项目实测数字并排成同一口径；
4. **成本假设**：8 小时人工、30 元/小时为**假设口径**，须显式写明；
5. **未修短板**：已披露的局限（高音、截断、噪声、校准、共享教师偏差、无用户验证）**不得**在叙事中消失或改写为已修；
6. **不虚构**：任何论断必须能指到仓库文件；无法指到的内容不进材料。
