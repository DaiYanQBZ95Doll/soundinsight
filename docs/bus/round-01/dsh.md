## 附录 A（长论证）

### A1. 为什么"跨模型判定"值得先做（而非直接人工金标）
- 成本对比：跨模型 ≈ **$0.01 / 0 人工小时**；人工金标 300 条 ≈ 1.5–3 人工小时；
- 决策价值：若跨家族 κ 高（如 >0.7），人工可**抽检 100 条**确认即可（省 1–2 小时）；
- 风险：κ 低时说明**两个 LLM 都不稳**，那更要人工——此时至少已知问题严重性。

### A2. 为什么保护项里 P2 优先于加检查
- 本次缺口的**根因**是两个文件各自实现了 `single_predict`（`demo_sound_v2.py` / `deployment/app.py`）；
- 加检查只能覆盖**我已想到**的分叉点；抽公共模块能让**未来所有**分叉自动消失；
- 成本：约半天（含回归验证）。
