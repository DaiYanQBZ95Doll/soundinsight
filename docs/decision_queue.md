# 当执行不再是瓶颈：决策队列工作法

> **缘起**：决策方 2026-10-01 提出——"智能体干活效率太高，以至于我又要探究接下来该怎样推进"。
> **本文件用途**：把"接下来做什么"从**人的即兴思考**，变成一份**可批量处理的决策队列**。
> 执行方维护此文件；决策方只需在队列里挑。

---

## 一、先把现象量化（用本项目自己的数据）

| 环节 | 人类节奏（估） | **本会话实测** | 倍数 |
|---|---|---|---|
| 代码/文档产出 | 每天数处改动 | **77 个提交 / 19 小时**（≈4/小时持续） | ~20–40× |
| 批量标注/复核 | 人工数天 | **10,233 条 LLM 复核 / 8.2 分钟** | ~100×+ |
| 全链验证 | 半小时起 | **13 步门槛链 / 6 分钟** | ~5× |
| **决策** | 每次数分钟–数小时 | **不变**（仍是人的带宽） | **1×** |
| **独立事实（人工金标）** | — | **1.5–3 小时，无法被替代** | **1×** |
| **真实世界动作**（提交/登录/录像） | — | **只能人做** | **1×** |

**结论**：瓶颈**已经从"执行"迁移到三处**——① 决策；② 独立事实（ground truth）；③ 真实世界动作。
继续优化执行，收益≈0；把省下的时间投到这三处，收益最大。

### 一个必须正视的副产品：**验证债**

本会话共发现并修复 **19 项缺陷**，其中：

- **约 12 项**由执行方自己的机械检查/自测发现（可继续机械化）；
- **约 7 项**由**红队**发现——**全是概念层**问题：口径未成对（两次）、分类主体误标"人工"、
  "闸门从未生效"、契约外新增、循环论证、分母未对账。

**这 7 项里没有任何一项是我的门槛链能抓到的**。也就是说：

> **执行速度越高，"独立审查"就越成为质量的实际限速步**——不是可选环节，而是结构性必需。

推论：**产出预算必须与审查预算匹配**。产得比审得快，可信度**下降**而不是上升
（本轮就是活例：456 → 作废、2,730 → 作废、审计退出码恒 0 却在报"全绿"）。

## 二、工作法：三条规则

### 规则 1：产出预算 ≤ 审查预算（**反直觉但最关键**）

- 每一批产出，先问"**谁能审、审多久**"；若审不完，就**不要生产**；
- 本轮的反例：一夜之间产出 6 类新分析 + 3 次对外材料改动，结果红队一轮就挑出 9 条，
  其中一条（分类主体）**性质是诚信红线**。若当时产出减半、审查加倍，本可早发现；
- 落地做法：**批次化**——每批产出后**停下来等审查**，而不是连续铺开。

### 规则 2：决策预注册（把"事后判断"变成"规则执行"）

- 事到临头再判断，消耗的是人最贵的带宽；**事前写死阈值**，事后只是套规则；
- 本轮已示范一次：方案 B 的升级线（长文本召回 ≥72%、高音 F1 ≥0.62、主指标 ≥0.74）
  **在测量之前**钉死 → 测完直接判"不升级"，**无需再开一次判断会**；
- 可复制的模板：`问题 → 选项 → 代价 → 判定规则（写死在测量前） → 触发条件`。

### 规则 3：人的时间只投在**不可替代**处

| 只在人这里能做的事 | 本轮状态 |
|---|---|
| 人工金标（独立于 LLM 的事实） | 工作表已就绪，**未做**（1.5–3 小时） |
| 真实世界动作（登录提交、录像、路演） | 待 10/7–10/8 |
| 价值判断（做不做、往哪走） | 本文件 §三 队列 |
| 关系/资源（找卖家用户、找顾问） | 未启动 |

> 反向清单：**凡是"再写一份文档/再跑一次分析/再加一个检查"能解决的，都不该占用人的时间。**

## 四、避免三个反模式（效率高的副作用）

| 反模式 | 表现 | 本轮实例 | 解药 |
|---|---|---|---|
| **产出过剩** | 产得比审得快 → 审查债 | 一夜 6 类新分析，红队一轮挑出 9 条 | 规则 1：产出 ≤ 审查预算 |
| **范围蔓延** | "既然这么快，那也能做…" | W4 开采 → 覆盖盲区 → 方案 B/C → v3 重训，一路膨胀 | **每次扩张都必须过"预注册判定线"** |
| **验证债** | 新声明多过能验证的量 | 456 / 2,730 / 审计退出码=0 三个假绿 | 每个新数字**当场配一个机械检查**或标注"未校准" |
