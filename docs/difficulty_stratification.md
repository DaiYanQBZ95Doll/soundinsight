# 分层分析：评测集与关键词闸门的结构关系（含一项**结构性局限**）

> 数据：`val_v3_test`（n=10,000，正例 128）+ v2 候选模型的缓存概率；阈值 **0.6**（v2 调优档）；
> 分组依据：`label_v3.py` 的一阶筛选词表（`SOUND_KEYWORDS`，23 词，词边界匹配）。

## 一、实测结果

| 组 | 样本 n | 其中正例 | 占全部正例 | 正例召回 |
|---|---|---|---|---|
| **A 组：含一阶关键词** | 1,313 | **128** | **100.0%** | 68.0%（87/128） |
| **B 组：不含任何关键词** | 8,687 | **0** | **0.0%** | —（无正例） |

## 二、这个结果说明什么（**重要，且此前未披露**）

1. **评测集在构造上继承了关键词闸门**：本项目的标签集是「关键词初筛 → LLM 复核」的产物，
   因此**只有含关键词的评论才可能被标为音质差评**——B 组正例为 0 不是模型的能力结论，
   而是**数据构造的必然结果**。
2. 因此 v1/v2 报出的所有指标（F1@调优 0.7220 等）**都是在「关键词可达」的子集上测得的**：
   - 该子集占全语料的 **13.1%**（1,313/10,000）；
   - **对不含任何关键词的评论（86.9%）**，管线的行为是"闸门直接丢弃"，模型**从未被评估过**。
3. 这与 W13 的结论一致（"入库漏检 0.0%"）：闸门不会漏掉**已标注**的真阳性，
   但**没有任何机制能发现闸门之外的真阳性**。

## 三、这对结论意味着什么（三种口径分开讲）

| 口径 | 现状 | 说明 |
|---|---|---|
| **关键词可达子集内的性能** | 有测量（F1 0.7220、P 77.0%／R 68.0%） | 现有全部指标的适用范围 |
| **全语料覆盖率** | **未测量** | 若真实差评中有相当比例不含任何关键词（如纯委婉表达），则全语料召回会被闸门压低 |
| **闸门外真阳性的量级** | **未知** | 需要"不依赖关键词的抽样 + LLM 复核"才能估——这正是 W4 四五星开采的做法（未含在 GATE 内） |

## 四、可执行的改进（下一阶段，不在本轮范围）

1. **无关键词抽样复核**：从 86.9% 的"闸门外"评论里随机抽 500–1,000 条做 LLM 复核，
   直接估计闸门外真阳性率 → 得到**全语料口径**的召回上界；
2. **放宽闸门 + 模型直判**：把闸门从"关键词"改为"模型概率"，即让模型对所有评论打分
   （成本：推理量 ×7.6，本地推理下仍可接受），从而**消除结构性覆盖盲区**；
3. 上述任一做完后，主文档应把"F1"补注为"**关键词可达子集口径**"。

## 五、诚实的边界声明

- 本页**不**声称"闸门外没有真阳性"，只声明"**我们没测过**"——这两者完全不同；
- 该局限**不影响**已验证的结论（子集内性能、长文本行为、校准、归因），
  但**限制**了"召回率"这一指标的外推范围；
