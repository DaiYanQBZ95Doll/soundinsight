# 数据漂移监控与重训计划（drift_plan.md）

> 目的：D6-D8 遗憾消除清单 Batch F —— 给出可执行的漂移监控方案，防止"模型上线后随评论语言风格漂移而失效"被评委问住。当前状态如实标注：方案已定义，尚未在真实业务流量上运行（无生产流量）。

## 1. 监控对象与频率

- 对象：每个卖家 CSV / 每个 ASIN 批次的模型判正率、平均概率分布、五类问题分布、文本长度分布、非英文占比。
- 频率：每次批量分析自动计算并附在报告"验证指标"节；月度汇总一次跨批次基线对比。
- 基线：val_v2 的分布快照（判正率 269/20000=1.35%，prob 分布十箱直方图，类别占比），已随 `val_preds_dump.csv` 冻结。

## 2. 指标与告警阈值

| 指标 | 计算方法 | 告警阈值（触发人工介入） |
|---|---|---|
| PSI（Population Stability Index） | 新批次 vs val_v2 的 prob 十箱 PSI | PSI > 0.2 |
| 判正率偏移 | 新批次判正率 / 基线 1.35% | 偏离 ±30%（相对） |
| 类别分布偏移 | 五类问题占比 vs 基线占比 | 单类占比变化 > 15 个百分点 |
| 文本长度中位数 | 新批次 vs 基线 | 中位数偏移 > 50% |
| 非英文占比 | 新批次非英文比例 | > 10% 时提醒语种覆盖缺口 |

## 3. 触发后的处置流程（纪律，与红线一致）

1. 告警 → 自动在报告中标注"分布偏移，建议人工抽查"。
2. 人工抽查 50 条新评论，确认是真实偏移还是标注口径变化。
3. 若确认为漂移：新评论进入 RLCA 弱标注池（规则初筛 + LLM 复核，绝不直接进训练集）。
4. 重训触发条件：连续 2 个月 PSI > 0.2 或判正率偏离 > 50%，且人工抽查确认漂移后，才允许在**新冻结验证集**上重跑阈值扫描/微调；旧模型、旧验证集、旧数字全部保留存档，新旧对比必须同时披露。
5. 冻结规则不变：val_v2、sound_model、multi_label_model 在重训决策生效前不得改动。

## 4. 现有证据（已实测）

- 跨年份分桶：2014-2022 各年桶 F1 无单调衰减（2022 桶 F1 0.80；见 year_split_eval 结果与 Q6）。
- 长度分桶：≤64 / 65-128 / >128 字符桶 F1 0.667 / 0.737 / 0.679，无严重长度依赖（length_bucket_eval.md）。
- 这两个证据降低了"风格漂移"的先验风险，但不能替代上线后的持续监控；2023 年桶样本少（5 正例），实时评论流表现未知，如实声明为未验证。
