## 3. 阈值选择偏差（**v1 从未披露**，本轮首次披露）

| 项 | 内容 |
|---|---|
| 事实 | `distilbert_cv.py`:90 在**同一折**上选取阈值并报告指标 |
| 影响 | v1 的 **F1@调优(0.9744) = 0.6871** 与 **CV 0.6234 ± 0.0240** 含**乐观偏置**（真实泛化值应更低） |
| 是否影响数字本身 | 数字是当时计算的真实结果，**不改**；改的是"如何解读"——须与"独立调参划分"口径区分 |
| v2 处置 | 阈值只在 `val_v3_tune` 上选、指标只在 `val_v3_test` 上报（W6 协议，已写入审计的机械检查） |

## 4. 评测划分的不可复现性（**本轮新发现**，属方法学说明）

| 项 | 内容 |
|---|---|
| 事实 | `val_v2.csv` 由早期 `labeled_llm.csv`（seed 42、20% 分层）生成；该文件此后被重建（RLCA 高音补捞、中置信剔除、时间戳考古重排），**行序已变** |
| 量化 | 用当前文件复算同一划分，与 val_v2 重叠 **15,891/20,000（79.5%）**，含正例 **198/251（78.9%）** |
| 后果 | ① 在 val_v2 上评估"用当前标签训练的新模型"会因**记忆**虚高（实测一次得 F1@0.5 = 0.9126，**该数字作废**）；② **v1 的划分无法由当前文件复现**，只能由冻结模型 + 冻结 `val_v2` 复现 |
| 对 v1 数字的影响 | **无**：0.6871`[v1]`／0.6241`[v1]` 是在**当时一致**的划分上得到的，仍然有效 |
| v2 处置 | v2 的一切指标报在**当前标签集的留出划分**（`val_v3_tune`/`val_v3_test`）；**两代不可直比**（采纳闸门 §四） |
