## 四、外部材料核验结论（激动线文档）

《激动线》按声学工程品类设定门槛，**不可直接作为本项目的验收标准**（其自述"这不是评论分析工具的标准"）。其中：

**已核到来源、可引用**：S1 亚马逊无线耳机差评结构（AMZ123 转载 Pangolinfo，2026-05，**厂商内容、需标注**）；S2 Harman 三分段 64%/15%/21%（**一手文献已核实**：Acoustics Today 2022 Spring, Sean E. Olive，主轴为低频）。
**核到来源但不可作为行业事实引用**：S3 "72% 未达音频基准"与"退货率降 18%"——出处为 SEO 内容站且其自身亦为转述（无原始报告）。
**未核实**：S4 ASR 引语、S5 两阶段 DNN 具体配置、S6 Olive 研究年限。
**裁定与标注要求**：见 `docs/external_sources_register.md`。

**可转化为本项目进化指标的 8 项**（详见 §五 W14–W17 与清单 A7）：听感词表覆盖度与漏检率｜星级分层归因一致性｜失败案例附录 ≥10 条｜置信度→动作可执行化率｜关键数字机械复算覆盖率｜型号级归因（最小样本量门槛）｜对抗性鲁棒性三项｜闭环层级自评。

**不可执行项（分母不存在）**：硬件参数级（mm/g）归因｜85% 物理归因准确率（缺"评论↔实测曲线"配对数据）｜真实改款闭环与跨品牌迁移（缺产业合作方）｜差评率预测 ≥70%｜三形态验证｜反事实归因。

**《激动线》方法论层面的三处问题**（并入质检方分析）：

1. **逻辑缺口**：该文用"测量→几何"的可行性文献（两阶段 DNN 逆向预测吸声结构尺寸、Helmholtz 共振器逆向设计）暗示"文本→几何"可行，但**中间缺"文本→测量"这一环**——而该文 §2.1 自己承认"学术界几十年没有完美答案"。缺的这一环正是我们唯一能做的事，也是它把门槛设成 85% 时忽略的环节。
2. **数据与结论的强度不匹配**：全部支撑数据为二手（其中一组已核实为厂商内容营销、一组为 SEO 转述、若干未核实），却用于支撑"价值量级完全不同"的结论。
3. **自相矛盾的阈值**：一边承认该映射"学术界未解决"，一边把 85% 定为"最低门槛"（§2.2 指标 2），而该阈值的分母在其自己的框架里无法定义。

## 六、验收门槛（v2 采纳闸门摘要）

采纳 v2 当且仅当六项全部成立（完整版见 `docs/v2_acceptance_benchmark.md` §七）：

1. **主指标**：`val_v3_test` 上 **F1@调优 ≥ 0.72**，或 PR-AUC ≥ 0.75（**阈值须在 `val_v3_tune` 上选取**；同集选阈值并报数即视为未达标）；
2. **双验证集**：`val_v2`（历史对比）与 `val_v3`（主指标）两套数字齐全，显式声明两代不可数值直比；**v1 的阈值选择偏差一并披露**；
3. **闭环**：截断桶召回 ≥70%（含方案对比与前后对比）+ 归因阈值按协议重选 + 高音处理完成；
4. **一致性**：全部验证报告 + 主文档 + 线上部署 + 视频 + 审计**一次性换代**，0 项滞留 v1；
5. **可核验**：模型 SHA256 + `threshold.json` + 训练命令 + 评估原始输出入库并登记于 v2 MODEL_CARD；
6. **诚实**：未修复短板仍在局限章节；已修复项移入"已解决"并注明原状态。

**降级分支**：第 1 条未达但 2–6 完成 → 仍可采纳（叙事改为边界测绘）；第 4 或 5 条未完成 → 整体回退 v1；第 6 条无法满足 → 不得提交。
