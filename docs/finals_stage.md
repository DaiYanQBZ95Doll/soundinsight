## 三、决赛提交要求（据官方模板原文，2026-09-24）

模板抬头：**AI+跨境黑客松巅峰赛 · 决赛入围定稿提交模板（天池渠道 · 团队一人提交即可 · 截止 10 月 8 日）**

**提交方式**（模板"提交说明"原文要点）：

1. 用 Word 编辑**本模板**，填写完成后把「本模板 + 附件材料」打包为**一个 zip** 提交；
2. zip 命名：**`团队名_方案名称_决赛入围定稿作品.zip`**；
3. 天池渠道**仅支持一个 zip**，所有材料放同一个包（包内可含子文件夹）；
4. 作品需具备**可演示的核心功能**（证明可实现、可使用、有业务价值）；
5. 其他补充材料（测试报告、用户反馈等）可附在文档末尾一并放入 zip。

**附件命名规范（模板第八部分原文）**：

| # | 材料 | 命名 |
|---|---|---|
| 1 | 主文档 | `团队名_方案名称_决赛入围定稿作品.docx`（或 `.pdf`） |
| 2 | Demo 压缩包 | `团队名_方案名称_Demo.zip` |
| 3 | 演示视频 | `团队名_方案名称_演示视频.mp4` |
| 4 | 其他材料 | `团队名_方案名称_其他材料.zip`（测试报告、用户反馈、补充架构图等） |

**主文档章节结构（模板第六至七部分 + 说明类）**：一、团队信息（表）｜二、参赛信息（表，参赛场景三选一）｜三、业务价值与市场分析（3.1 目标用户与痛点 / 3.2 应用场景与使用流程 / 3.3 商业价值与预期效果（要求可量化）/ 3.4 市场前景与落地可行性）｜四、产品功能与使用说明（4.1 产品简介 3–5 句 / 4.2 核心功能清单 4 条 / 4.3 使用说明，可配截图）｜五、技术架构及调用模型说明（5.1 系统架构图 / **5.2 调用的阿里云百炼模型**（表：模型标识｜用途｜调用方式/链接）/ 5.3 技术组件说明）｜六、项目开发及阶段成果说明｜七、提交物清单（勾选）+ **在线链接填写表**（GitCode 仓库（可选）/ 线上 Demo 地址 / 产品演示视频链接 / 测试账号或体验地址）｜八、附件命名规范｜九、注意事项。

**与复赛模板的实质差别（影响产物）**：

1. **主文档不再是自拟的 v4 文档，而是"填写后的这份模板"**（.docx 或 .pdf）——现有 `competition_v4.md` 的内容需按模板九节重新映射；
