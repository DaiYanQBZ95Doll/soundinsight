# 缺憾与期许总清单（项目级汇总）

> 用途：把"还没做好的"和"想做得更好的"两件事收在一处，便于决策与交接。
> 定位：**只做汇总与索引**——明细以源文件为准（一处一事实）；本文件不重复各报告的完整推导。
> 编制：2026-09-24 ｜ 事实来源标注在每条内；未标注来源的判断性内容会写明"属判断"。

---

## 〇、怎么读

- **缺憾**分四类：① 影响指标（模型/数据）② 影响可信度与口径 ③ 结构性/不可逆 ④ 工程与交付层。
- **期许**分三类：① 闸门内（决赛采纳 v2 的必要条件）② 决赛交付（10/8 硬性）③ 赛后/毕设（长期）。
- 状态栏：`未修` / `部分` / `已披露` / `已修` / `不可修`（当前条件下）。

| # | 缺憾 | 量化证据 | 来源 | 状态 |

| B3 | 训练与验证标签同源 | 共享教师偏差 → LLM 对照含同源红利，deepseek 0.9400 **不得**作绝对上限（应取 qwen 0.9149） | `llm_baseline.md` §2b、`docs/v2_acceptance_benchmark.md` §四 | 已披露 |

| B7 | LLM 成本估算缺官方出处 | deepseek-chat 输入 $0.27/M、输出 $1.10/M，按 82%/18% 估 3,000 次约 $0.1≈¥0.7；**须补价目链接与抓取日期**，否则只能作"估算" | 同上 §6.3 | 待补出处 |

## 四、依赖与不可逆说明

- **时序**：E1–E10 产生数字 → 必须在 T-3（10/5）数字冻结前完成；F1/F2 定稿与 F5 存证随后；T-1 只做打包与上传演练（见 `docs/v2_acceptance_benchmark.md` §8.2）。
- **依赖链**：E5（val_v3 划分）→ E1/E2 的指标可信；E2 对外引用依赖"按 §四 协议重选"；E10 依赖 v2 产物实际生成。
- **不可逆**：C1（无渠道的用户验证）、C7（v1 已提交包不可改）、B3（共享教师偏差，除非重造标签）。
- **可逆但需显式声明**：B2 的勘误方式、B1 的历史偏差披露。
