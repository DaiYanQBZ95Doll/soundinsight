## 〇、阅读约定

1. **阈值档**：F1 / 精确率 / 召回率必须带阈值档——`@调优(0.9744)` 或 `@0.5`。本项目两档值不同，混读即错。
2. **代际标签**：`[v1]` = 复赛已提交冻结口径；`[v2]` = 决赛口径（尚未产生）。凡两代数字并排处必须各自标注。
3. **状态标记**：`未修` / `已测量未修` / `未披露` / `已闭合` / `不可执行` / `未启动`。
4. **历史标记**：凡引用已作废表述（勘误、旧口径、过时状态）处，均显式标注其历史性质，不得作为现状引用。

## 三、结构性观察

1. **技术侧缺憾集中且可修**：A1 的八项中，A1-3（截断）、A1-4（高音）、A1-6（归因阈值）合为"三处已测量未修的伤口"，A1-8 为"一处从未披露的偏差"——四件都能在 v2 中闭合。
2. **文档侧硬伤已成小量**：A4 五项中，A4-21（百炼栏）与 A4-23（审计工具链）已于 2026-09-28 闭合；剩 dummy 标签勘误、PDF 生成路径声明、非英文表述矛盾三项，均为低成本的文字级修正。
3. **B 类清单中真正改变项目层级的只有三件**：B1-1 截断修复（完整闭环）、B1-4 四五星开采（数据触底）、B2-10 时序功能（从单次分析到持续监控）。其余为加固与铺陈。
4. **不可执行项已明确**：A3-14 / B4-22（真实用户）受渠道限制，属客观不可执行，应在文档中记录原因而非仅记结果。
