| B1-6 | **交叉拟合 / tune-test 分离** | 消除 A1-8 的阈值选择偏差，使 0.72`[v2]` 可信 | 优先级高于目标值本身 |
| B1-7 | **概率校准** | 温度缩放 / Platt（在独立调参划分上拟合、在测试划分上报告） | 配合 B2-12 置信分层展示 |
| B1-8 | 数据效率单值 | "达到 F1@0.5 = 0.65 所需标注量" | 回答"数据够不够" |
| B1-9 | 非音频子集误报率 | 在现有数据内划非音频/非耳机子集，计算该子集误报率 | 替代需另行下载的跨品类测试；量化泛化性 |
| B1-10 | **统计检验进阶** | 效应量（Cohen's d / Cliff's delta）+ 多重比较校正（Bonferroni / FDR） | 与 B1-5、B1-6 配套：v2 若跑多组对照（基座矩阵、消融组），不做校正如"多试几次撞出一个显著"；成本极低 |
| B1-11 | **传统深度基线扩展** | 补 fastText / BiLSTM 两类非 Transformer 基线 | 现基线池仅 dummy / TF-IDF+LR / TF-IDF+SVM，缺"传统深度"一档；分钟级训练，让"深度学习方案值得"的论证闭环 |

### 5.2 时间盒算术警示（开工前必须先解决）

`docs/v2_acceptance_benchmark.md` §8.1 给出的 B1 时间盒合计 **5.25 天**（四五星 1 + 标签重建 0.5 + 重训与 CV 1 + 长文本 1 + 归因阈值 0.5 + 基座 0.5 + 非音频 0.25 + 换代审计 0.5），而 10/1–10/4 仅 **4 天**；若把本轮新增的 B1-10 ~ B1-13 计入，缺口进一步扩大。

三种解法（可组合，由决策方选定）：

1. **提前启动**：9/29–9/30 先做不依赖决策的项（长文本方案对比、基座矩阵、传统基线扩展），把 4 天窗口留给"换底"主干链路；
2. **后移冻结**：T-3 改为 10/6，压缩材料窗口，视频与主文档并行推进；
3. **缩减范围**：暂缓 B1-5（基座矩阵）、B1-9（非音频子集）、B1-11（传统深度基线）、B1-13（多任务学习），保 B1-1 / B1-2 / B1-3 / B1-4 / B1-6 五项主干。

**不含数字变动的项**（B2-16 ~ B2-21、B7-20 ~ B7-22、B5-25 ~ B5-29，以及 §A4 / §A6 的文字与工程修正）可与数字窗口并行，不占这 4 天。

> **执行方附注（2026-09-28，据实测速度核对时间盒）**：上表的时间盒按"人类执行速度"估算，与本项目**实测训练速度**差距较大，可能把 4 天窗口误判为不足。实测数据：
> - 最终二分类模型单次训练 **125 s/epoch**（3 epoch 约 6 分钟）——`results_summary.md` 第 46–49 行；
> - 清洗标签 5 折 CV 全流程 **2,921 s ≈ 49 分钟**（逐折累计 598 → 1202 → 1791 → 2360 → 2921 s）——同文件第 36–40 行；
> - 因此"二分类重训 + 阈值扫描 + 5 折 CV"的真实 wall-clock 是**约 1 小时**，而非 1 天；基座矩阵（4 个基座 × 分钟级）约 1 小时；长文本四方案对比按 4 次训练+重评估算亦在小时级。
> - **真正的关键路径不是训练，而是"新增候选的 LLM 复核体量"与"人工抽检"**：复核是 API 调用（可并行），体量取决于四五星候选数（B1-4 的产出量目前未测），人工侧 30–60 分钟不可压缩。
> - 由此对 §5.2 三种解法的执行方判断：**方案 1（提前启动）与方案 3（缩减范围）都在 4 天内可行**；GPU 串行约束的实际影响是"小时级排队"而非"天级争用"。此判断基于实测速度，与复盘 §4.4"计划必须按实测速度重算"的结论一致；**取舍仍由决策方定**。
