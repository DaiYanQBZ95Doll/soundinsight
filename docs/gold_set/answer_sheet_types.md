> **判什么**：这条评论**给了差评**（1–3 星）时，原因属于哪些类型？**多选**。

> 编码：**1=连接/配对**｜**2=续航/充电**｜**3=做工/耐用**｜**4=佩戴/舒适**｜**5=麦克风/通话**｜**6=功能/操作**｜**7=物流/包装**｜**8=价格/性价比**｜**9=客服/售后**｜**10=描述不符/假货**｜**11=音质(听感)**｜**12=非负面/无抱怨**｜**13=其他**
> 多选用逗号分隔（例：`3,6`）；**0 = 无法判断／其实不是差评／没有明确抱怨**。
