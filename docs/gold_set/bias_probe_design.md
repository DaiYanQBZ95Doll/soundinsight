# 偏向探针设计：量化「翻译与解析」对人工判读的影响

> **动因**：决策方指出，「执行方给出的翻译与解析**对我的判读会造成什么影响**」是本项目的关键问题之一
> （该分析由红队 Kimi 主导）。执行方在此提供**可复现的测量机制**并做**自我披露**。

## 一、执行方自查到的具体风险（诚实披露）

| 风险 | 说明 |
|---|---|
| **判据泄漏** | 完整答题卡的「解释」栏含 **声音表述** 一项；而决策方判据正是「是否在说音质」——该栏与判据高度相关，**客观上把答案递给了判读人** |
| **措辞锚定** | 即使措辞中性（「提到…卡顿/嗡嗡声」vs「未提及声音相关内容」），二值化叙述仍在暗示方向 |
| **顺序效应** | 我方格式把判定放在原文/翻译/解释**之后**；Kimi 的卡把判定放在**最前**——两种排布可能产生不同锚定 |
| **翻译用词** | 译文由 LLM 生成，用词选择（「卡顿」vs「杂音」）可能影响归类 |

## 二、已实施的缓解（可复跑验证）

1. **强制中性生成**：提示词明令「只描述、不判定」；脚本对解析字段做**判定词表自检**，命中即打回
   （实测打回 21 次）；重试耗尽则**只给翻译、不给解析**（7 条）。
2. **禁词零容忍**：`抱怨|差评|负面|好评|complaint|negative|positive|判定|属于音质…`。
3. **探针卡**：`docs/gold_set/bias_probe_sheet.md` —— **40 条随机子集、只给英文原文**（种子 20261002，可复现）。
4. **量化**：`python score_bias_probe.py` 输出一致率、κ、**逐条差异**与**方向性**。

## 三、预登记判读规则（先写定，避免事后挑解释）

| 观察 | 结论 |
|---|---|
| 一致率高（>90%） | 材料影响小，人工判定的独立性较强 |
| 一致率低 + 方向性偏「是」 | **材料推高了「是」的比例** → 覆盖类数字可能被高估，材料须限定 |
| 一致率低 + 双向 | 材料主要增加**噪声**，而非方向性偏差 |
| 某类条目系统性改判（如全为 2→1） | 该类解析措辞有引导性，应针对性改写 |

## 四、与红队分工

- **机制与自查**（本文件 + 探针卡 + 评分器）：执行方；
- **影响分析**（材料如何影响判读、与 DSH/Qwen 方案的差异）：**红队 Kimi 主导**（决策方指派）；
- 执行方**不预判**其结论，只保证数据可得、可复现。

## 五、复跑命令

```
python make_bias_probe.py        # 重新生成探针卡（同种子 → 同子集）
python score_bias_probe.py       # 与主卡对比出结论
```
