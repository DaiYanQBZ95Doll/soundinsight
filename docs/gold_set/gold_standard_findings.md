## 二、逐层结果与混淆矩阵

### S1｜闸门外随机（校准"闸门外真阳性率 1.33%"）

|  | LLM=1 | LLM=0 |
|---|---|---|
| **人工=1** | 3 | 0 |
| **人工=0** | 1 | 90 |

- 人工真阳性率 **3/99 = 3.03%**（95% CI 1.04%–8.53%）；原口径 1.33%（LLM 探测 4/300）
- 一致率 98.9%、κ 0.852（极好）——**点估计是原口径的约 2.3 倍，但 CI 重叠，不能据此推翻 1.33%**

### S2｜四五星候选池（校准 W4 的 1.0%／3.1%）

|  | LLM=1 | LLM=0 |
|---|---|---|
| **人工=1** | 0 | 7 |
| **人工=0** | 6 | 83 |

- 人工 7/100 = 7.0%；LLM 6/100 = 6.0%——**两者完全不重叠**，κ **−0.072**（比随机还差）
- 含义：该池内 LLM 判定与人工判定**无相关**；W4 的 ≈20／≈95 估计**未获独立支持**

### S3｜现有已标注集（量标签质量本身；随机抽 50 LLM 正例 + 50 LLM 负例）

|  | LLM=1 | LLM=0 |
|---|---|---|
| **人工=1** | 13 | 2 |
| **人工=0** | 30 | 44 |

- **LLM 正例精确率 = 13/43 = 30.2%**（95% CI 18.6%–45.1%）
- LLM 召回（以人工为准）= 13/15 = 86.7%；负例判负 44/46 = 95.7%
- **误判来源拆解**：30 条"人工判不是"中，**28 条是口径外产品**（条形音箱／蓝牙音箱／线缆／天线／
  音频眼镜等），**只有 2 条是耳机类真误标**（对讲机耳机线、耳机插孔扬声器）

## 三、这改变了什么（**必须修改对外表述**）

| 项 | 原表述 | 金标后的诚实表述 |
|---|---|---|
| **覆盖总量** | 成对口径 **2,461（52.0%）／2,826（45.3%）** | 该数字基于 **LLM 口径的 1.33%**；人工点估计 3.03% → 覆盖降至 **约 32%（严格 32.5%／宽松 31.9%）**，CI 跨度 **14.5%–58.1%**。**必须并列两个口径**，不得只报 52% |
| **已标注正例集规模** | 1,280 条（"冻结正例"） | 随机抽样显示其中 **约 70% 为口径外产品**（音箱/线缆/天线等），耳机音质正例的点估计约 **380–430 条**；"1,280"应改述为"**声学相关抱怨集**"而非"耳机音质差评集" |
| **标签质量** | 未量化 | 以人工为准：**精确率 30.2%、召回 86.7%**——标签**过宽**而非"错"，根因是**产品口径过松** |
| **W4 覆盖分量** | ≈20（严格）／≈95（宽松） | **未获独立支持**（S2 层 κ −0.072）；应标注为"仅 LLM 口径" |
| **主指标解释** | F1 等基于 `val_v3_test` | 该测试集由上述标签体系派生 → **指标测的是"声学抱怨"而非严格"耳机音质差评"**，须加限定词 |

## 四、为什么这不是"灾难"而是"提前发现"

1. 这些数字**以前从未被独立检验**；现在有了真值，**表述可以改对**；
2. 根因是**口径**（产品筛选过松）而非模型能力：同一批数据上 LLM 的**召回 86.7%**说明它并没有乱标；
3. 修正路径明确：**按产品类型收紧口径**（重新筛选正例集）→ 属 v3 级工作，但**结论已在手**。

## 八、追加样本与第二遍判定（2026-10-02 晚，两份卡均已填）

### 8.1 闸门外比率：**人工证据收敛到原 LLM 口径**

| 样本 | 人工判正 | 比率 | 95% CI |
|---|---|---|---|
| S1（首轮 100，可比对 95） | 3 | 3.16% | 1.08%–8.88% |
| **S4（追加 100）** | **0** | **0.00%** | — |
| **合并（195）** | **3** | **1.54%** | **0.52%–4.42%** |
| 原 LLM 口径（300 条复核） | 4 | 1.33% | — |

**读法**：首轮 3.03% 是 n=95 的**上偏波动**；追加 100 条一条正例都没有，合并后 **1.54%（CI 0.52–4.42%）
与原 LLM 口径 1.33% 相容** → **闸门外比率获得独立人工佐证**，而非被推翻。

**覆盖修订（成对口径，labeled = 1,280）**：

| 采用比率 | 严格覆盖 | 宽松覆盖 |
|---|---|---|
| 原 LLM 口径 1.33% | 52.1% | 45.4% |
| **人工合并点估计 1.54%** | **48.5%** | **42.0%** |
| 人工 CI 下界 0.52% | 72.9% | 65.8% |
| 人工 CI 上界 4.42% | 24.8% | 20.7% |

> **结论**：原报的 52.0%／45.3%（LLM 口径）**站得住**；引入人工真值后的点估计为 **48.5%／42.0%**，
> 两者差 ~3.5 个百分点，**远小于**首轮 n=95 时担忧的"降至 32%"。

### 8.2 判定稳定性（同一批 300 条、两份不同的卡）

| 项 | 值 |
|---|---|
| 一致率 | **91.0%** |
| κ | 0.339 |
| 改判 | **27 条（9.0%）** |
| 方向 | 1→0（4）｜1→?（2）｜?→0（15）｜0→?（6）——**变为"是"的：0 条** |
| 两遍阳性数 | 第一遍 25 → 第二遍 19 |

**诚实限定**：两遍之间变的**不只是呈现顺序**（我方卡判定在末尾、Kimi 卡判定在开头），
**材料也不同**（Kimi 的译文与解析为独立产出；其卡头亦披露有 12 条的措辞可能间接受我方译文影响）。
故 **9.0% 的改判率是"材料+呈现"合计效应的上界**，不能单独归因于顺序或措辞。
方向性一致（**没有任何一条从"不是/无法判断"翻成"是"**）说明：换一套材料不会让我们**多报**正例，
只会更保守 —— 这对覆盖类数字是**安全方向**。

### 8.3 仍然成立的最重要一条（不受本轮影响）

**S3 显示已标注正例的 LLM 精确率仅 30.2%**（误判 30 条中 28 条为口径外产品）。
即"1,280 正例"应改述为「**声学相关抱怨集**」——**这条未被追加样本改变**，
仍是材料中最需要修正的口径问题（决策队列 **D-Q8**）。

### 9.1 全量口径判定（分类器已经人工真值验证）

| 目标 | 规模 | 耳机家族 | 主要构成 |

| 冻结点测集 | 10,000 | 778（7.8%） | 非音频 4,831｜无法判断 2,364｜线缆 1,056｜其他音频 535｜音箱 392 |

**分类器可靠性**（用决策方的人工真值验证，S3 的 50 条 LLM 正例）：
**召回 92%、误报 17%、精确率 71%** → 上表数字自带该量级误差，宜读作"量级与方向"。

### 9.2 范围内重评（纯后处理，未重跑模型）

| 组 | n | 正例 | F1@0.5 | F1@调优 | PR-AUC |
|---|---|---|---|---|---|
| 全测试集 | 10,000 | 128 | 0.7206 | **0.7220** | 0.7811 |
| **耳机家族（范围内）** | 778 | **48** | **0.6966** | 0.6897 | 0.7783 |

**必须同时读的两点**：
1. 测试集的 128 条正例中 **80 条（62.5%）不是耳机音质差评** —— 主指标测的是"声学抱怨"口径；
2. **限定到耳机口径并不会让指标变好**（0.6966 < 0.7220，且组内仅 48 条正例）→
   本项目**不主张**「收紧口径可提升性能」；D-Q8 的选项 A（重筛重训）因此**不是**为提分，而是为**名实相符**。

### 10.1 两遍判定的配对检验（McNemar）

| 配对（2×2，`?` 记为负） | 数 |
|---|---|
| 两遍都判"是" | 19 |
| 第一遍"是" → 第二遍"不是" | **6** |

**McNemar 精确检验：双侧 p = 0.0312** → 改判方向**显著不对称**：
换成 Kimi 的材料/呈现后，判定**单向更保守**（没有任何一条翻向"是"）。
> 归因限制：两遍之间**材料与呈现同时改变**，且第二遍存在记忆效应，故本检验证明"存在方向性影响"，
> **不能**分解出顺序与措辞各占多少。
