# 人工金标协议（独立于 LLM 的唯一事实来源）

> **为什么需要**（红队 2026-10-01 质询）：本项目当前**全部**验证标签——包括 `val_v3_test`——
> 都出自 LLM，而模型也是用 LLM 标签训练的。这等于**让同一个证人既当眼睛又当尺子**：
> 用它发现盲区、用它扩标签、再用它验成绩。附录 B 第 4 条早已披露「共享教师偏差」，
> 但任何「扩充后上限更高」的说法都建立在这块流沙上。
>
> **本协议的定位**：立一块**非 LLM 来源**的金标，作为此后所有对外 F1/召回、以及
> LLM 判定可靠度的唯一校准依据。**在执行方看来，它比 B/C 的排期更优先。**

---

## 一、已备好的东西（执行方 2026-10-01 完成）

| 文件 | 内容 |
|---|---|
| `docs/gold_set/worksheet.csv` | **300 条盲评工作表**（Excel 可直接打开；只含「编号 + 原文」，**不含**任何 LLM 判定或模型分数） |
| `docs/gold_set/worksheet.md` | 人读版（便于快速浏览） |
| `v2/gold_set_key.json` | 映射密钥（编号 ↔ 行号 ↔ LLM 判定）——**勿给标注者** |
| `make_gold_set.py` | 可复算抽样（seed 42；`--per-stratum N` 可缩到 50 条/层 ≈ 50–90 分钟） |
| `score_gold_set.py` | 评分器：一致率、**Cohen's κ**、Wilson 区间；`--self-test` 已用合成数据验证 |

## 二、分层设计（各 100 条，均取自**已有 LLM 判定**的条目，以便逐条对齐）

| 层 | 来源 | 该层回答的问题 |
|---|---|---|
| **S1** | 闸门外**已复核**的 300 条中随机 100 | 「闸门外真阳性 1.33%」这一说法**准不准** |
| **S2** | 四五星池**已复核**的 293 条中随机 100 | W4 的 **1.0%／3.1%** 准不准 |
| **S3** | 现有标签集：50 条 LLM 正例 + 50 条 LLM 负例 | **现有标签本身的质量**——全部指标可信度的天花板 |

实测三层 LLM 判定分布：S1 4/100 判正、S2 7/100 判正、S3 50/50（构造如此）。

## 三、怎么做（人侧，约 100–175 分钟）

1. 用 Excel 打开 `docs/gold_set/worksheet.csv`；
2. 在「**人工判定(1=音质差评/0=不是)**」列逐条填 `1` 或 `0`：
   - 判据：**这条评论是否在抱怨耳机/耳塞/头戴的音质**（低音／清晰度／杂音／音量／高音）；
   - 无法判断产品是不是耳机 → 填 `?`（单列统计，不计入一致率）；
   - **不要**参考任何模型或工具输出（表里也没有）。
3. 填完保存，回来告诉执行方，或直接跑 `python score_gold_set.py`。

> 想缩短：`python make_gold_set.py --per-stratum 50` 生成 150 条版（≈50–90 分钟）；300 条版区间更窄，建议优先。

## 四、评分器产出

- 逐层**一致率**与总体 **Cohen's κ**（参考：<0.2 差／0.2–0.4 一般／0.4–0.6 中等／0.6–0.8 良好／>0.8 极好）；
- **人工口径**重算的三个率：闸门外真阳性率、四五星池率、现有标签准确率（各带 Wilson 95% CI）；
- 结论文件：`docs/gold_set/agreement_report.md`、`v2/gold_set_agreement.json`。

## 五、结果如何被使用（预先声明，避免事后挑选）

1. **全部对外 F1/召回**：改为在**人工金标口径**下报告（或在 LLM 口径旁并列人工口径）；
2. **`1.33%` 等 LLM 率**：在一致率出来前一律标注「LLM 口径，未经人工校准」（**已标注到主文档附录 B 与三份报告**）；
3. **升级判定**：若提案升级到方案 C，**必须附带人工金标结果**（预注册规则见 `docs/reassessment_after_credential.md` §「预注册判定线」）；
4. **κ 若低于 0.4**：说明 LLM 标签噪声显著，现有全部指标须**重估并如实披露**——该结果同样记录，不因不利而延后。

## 六、边界（诚实声明）

- 300 条是**抽样**，非全量人工复核；Wilson 区间一并给出；
- **单一标注者**（与项目既有情况一致）→ 无法计算标注者间一致性，只能算「人与 LLM」的一致性；
- 人工金标**不能修复**「训练标签同源」这一偏差（训练仍用 LLM 标签），它校准的是**评测**可信度；
  若要修训练侧偏差，需要人类标注的训练数据（远超本轮范围）。
