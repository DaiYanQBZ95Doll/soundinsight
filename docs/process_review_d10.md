# SoundInsight 全流程总结（D1-D10 复盘，2026-09-08）

> 项目：SoundInsight 蓝牙耳机音质差评智能归因系统（AI+跨境黑客松巅峰赛·复赛，AI 市场洞察赛道）
> 团队：更新世界的锋芒。本文档回答两个问题：**做了什么**、**怎么做的**。
> 所有数字以 `results_summary.md` 为权威源。

## 一、问题与解法（一句话链路）

- **问题**：跨境耳机卖家的差评是英文的、量大的、音质问题藏得深的——41.5% 的音质差评藏在三星"温和不满"里（本项目实测），通用情感工具只分正负、不归因，人工翻 1000 条要 8 小时。
- **解法链路**：`[10 万条真实评论] → [RLCA 两阶段标注] → [DistilBERT 二分类 + 五类多标签归因] → [Agent 报告 / Gradio Demo / HTTP API / 在线创空间]`

## 二、数据：怎么来的、怎么标的

1. **获取**：HTTP Range 分段拉取 McAuleyLab Amazon Reviews 2023 的 `electronics_prefix.bin`（128MB gzip 前缀）→ 解析出 10 万条评论（text / rating / timestamp）。时间戳为原始字段，100% 恢复（2000-10-07 → 2023-03-18），字段考古见 `docs/dataset_audit.md`。
2. **RLCA 两阶段标注**（Rule-LLM Cascade Annotation）：
   - 阶段 1 规则初筛：关键词单词边界匹配 + 星级阈值 → 1502 条候选（精度仅 51.8%）。
   - 阶段 2 LLM 复核：deepseek-chat 逐条复核去伪 → 精度升至人工抽查 78%（n=50，Wilson 95% CI 64.8%-87.2%）。
   - 三星召回补漏：三星评论中 41.5% 实为音质差评被规则漏检，补回 479 条。
3. **数据提纯**：LLM 置信度分层（高置信 471 / 中置信 8 / 低置信 0）→ 8 条中置信人工复核仅 3/8 通过 → 按质量线全部剔除。
4. **正例口径演进**：1257（冻结实验口径）→ 1288（高音补捞 +31）→ **1280**（中置信移除 8）。冻结数字与实验全部基于 1257 口径。
5. **标注噪声量化**：从 val_v2 的 164 个错误样本中筛出 16 条噪声候选，用户人工终审 **15/16 确认** → 噪声率约 **9.1%**（95% CI 5.6%-14.5%，候选集确认率下的下界估算）。
6. **时序验证**：年份分桶 2014-2022 无单调衰减（2022 桶 F1@0.5=0.8049，覆盖 19,996/20,000），月度音质差评率趋势图 `trend_over_time.png`。

## 三、模型：怎么训的（全部冻结，未重训）

- 基座：DistilBERT-base（66M），Hugging Face 官方源不可达 → ModelScope 镜像。
- 训练配置：1:10 欠采样（约 1006 正例 + 10060 负例）、lr 2e-5、batch 16、epochs 3、阈值扫描、5 折交叉验证；多标签模型为独立 sigmoid 头。
- **冻结结果**：二分类 val_v2（20,000 条 / 251 正例）**F1 0.687 @ 阈值 0.9744**；5 折 CV 0.6234±0.024；AUC-PR 0.7191；Welch t 检验 p=0.000932，显著优于 SVM 0.497 / LR 0.410 / dummy 0.025。混淆矩阵 TP=179/FP=91/FN=72（GPU 重跑 TP=178/FN=73 已显性调和）。
- 多标签五类归因：宏 F1 0.65（低音 0.79 / 清晰度 0.77 / 杂音 0.84 / 音量 0.84 / 高音 0，样本稀缺已披露）；复合差评（≥2 类）占 23.5%。
- 消融 3 组（无采样 / class_weight / Focal Loss）→ 现方案最优；学习曲线用无泄漏 bootstrap（100→1257 正例，0.4067→0.6179）。

## 四、验证体系：怎么验证的（本项目核心差异化）

1. 固定验证集 val_v2（20,000 条 / 251 正例）红线冻结，所有评估同口径。
2. **LLM 对照**（1000 条固定子集 = val_v2 正例全集 + 749 负例采样，同提示词）：
   - deepseek-chat：零样本 0.940 / 5-shot 0.873 / 复核 0.846（tokens 24.9 万）
   - qwen3.7-plus（百炼 Token Plan）：零样本 0.9149 / 5-shot 0.8937 / 复核 0.8661（tokens 49.1 万）
   - 小模型同子集 0.826；口径声明完整：循环性红利（deepseek 参与标签制作）、预训练记忆无法排除——数字是相对参考而非绝对水平。
3. 长度分桶（tokenizer 口径）：≤64 token 0.708 / 65-128 0.749 / >128（截断桶）0.565——截断暴露面首次量化。
4. 边界探针 12 条 7/10；发现多语言评论被静默判负 → 产品层显式拒绝（is_unsupported）。
5. 校准：十箱 ECE 0.0122，决策区间严重过度自信（[0.9,1.0) 置信 0.975 vs 实际正例率 0.555）→ 全链路输出加"概率未经校准，仅供排序参考"。
6. 错误分类学：FP=91 / FN=73；误报 54.9% 为"其他问题"（物流/耐用/连接/非音频产品）、漏报 58.9% 为委婉表达与双面评价；标注噪声 9.1%（人工终审）。
7. 吞吐实测：GPU 1.76s / CPU 28.4s per 1000 条（含多标签归因）；"2 分钟/99.6%"旧表述全部改为实测口径。
