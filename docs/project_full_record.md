## 一、项目定位

**SoundInsight——面向跨境电商耳机卖家的音质差评自动识别与五类问题归因系统。**

- 一句话链路：`[10 万条真实评论] → [RLCA 两阶段标注] → [DistilBERT 二分类 + 五类多标签归因] → [Agent 报告 / Gradio Demo / HTTP API / 在线创空间]`
- 目标用户：跨境电商平台耳机类目中小卖家（团队 <10 人，无专职数据分析师）
- 核心发现（本项目实测）：**三星评论中 41.5% 实为音质差评**，是规则与通用情感分析工具的漏检盲区
- 价值主张：把人工 8 小时/千条的差评梳理压缩到秒级（GPU 实测 1.76 秒/1000 条），且把"读不懂的英文长评论"变成"可执行的五类问题清单"

## 二、前期探讨（选题与可行性）

1. **选题思路**：不从宏观数据模型出发，而从"我最熟悉的品类"出发——队长日常使用头戴式耳机，对音质好坏有判断力，因此选择耳机作为切入口，再切换到卖家视角看问题。
2. **真实评论翻查的发现**：卖家不缺数据，缺的是结构化——音质抱怨散落在大量英文长评论里，人工逐条翻看既慢又难以归类统计，导致产品迭代与客服话术滞后。
3. **痛点归纳（四类）**：差评数量大（日均 50-200 条）｜语言杂（英文为主夹杂其他语种）｜音质问题隐蔽（41.5% 藏在三星）｜改进滞后（无系统归类）。
4. **竞品与空白**：Helium 10、Jungle Scout 等主流 SaaS 只做通用情感分析，不识别"低音浑浊、高音刺耳"等专业声学问题，也不做细粒度归因——这是差异化切口。
5. **三条使用场景**：选品（竞品 ASIN 音质差评对比）｜优化（自家评论 CSV 一键出问题分布与整改建议）｜迭代（改版前后报告对比）。
6. **可行性预研**：8GB 显存（RTX 4060 Laptop）约束下选轻量基座 DistilBERT；确认数据源可获取（McAuley Lab 公开数据集）；确认 Gradio 能在本地与云空间双形态运行。

## 五、复赛技术实现（逐步记录）

### 5.1 数据扩充
- 通过 HTTP Range 分段拉取 `electronics_prefix.bin`（128MB gzip 前缀）→ 解析出 **10 万条**评论（字段：text / rating / timestamp）。
- 时间戳为原始字段，**100% 恢复**（2000-10-07 → 2023-03-18）；字段清单与数据质量见 `docs/dataset_audit.md`。
- 时间戳恢复脚本 `restore_timestamps.py`，逐条文本精确匹配校验。

### 5.2 RLCA 两阶段标注（Rule-LLM Cascade Annotation）
1. **规则初筛**：单词边界匹配 + 音质关键词表（低音/清晰度/发闷/失真/电流声等 20 余词）+ 星级 ≤2 星 → 候选 **1,502 条**，精度仅 **51.8%**（弱标注）。
2. **LLM 全量复核**：deepseek-chat 逐条复核去伪（temperature=0）→ 精度提升至人工抽查 **78%**（n=50，Wilson 95% CI 64.8%-87.2%）。
3. **三星召回补漏**：对三星评论复核 1,271 条，确认 **479 条**漏检正例（三星漏检率 **41.5%**）。
4. **置信度分层**：高置信（≥0.8）471 条直接保留；中置信（[0.60,0.80)）8 条；低置信 0 条。
5. **中置信人工复核**：人工审核 8 条仅确认 3 条（37.5%），低于 60% 质量线 → 按决议**全部剔除**（记录于 `confidence_tiered.md`，备份 `labeled_llm_before_mid_remove.csv`）。

### 5.3 正例口径演进与冻结
| 阶段 | 正例数 | 说明 |
|---|---|---|
| 初赛 | 63 | 前 5,000 条数据 |
| 复赛冻结口径 | **1,257** | 全部实验与交叉验证的数字基准（1.26%） |
| 高音补捞后 | 1,288 | 新增 31 条（高音标签 84→124，X=31 新增 + Y=9 补标 = 40） |
| 中置信剔除后 | **1,280** | 当前工作集（不含在冻结实验口径内） |

**冻结时点与内容**：模型权重、`val_v2.csv`（20,000 条 / 251 正例）、训练脚本、以及 `results_summary.md` 中的全部指标数字；冻结后任何人不得改动，包括队长本人。

### 5.4 二分类模型
- 基座 DistilBERT-base-uncased（66M，HF 官方源不可达 → ModelScope 镜像）。
- 训练：1:10 欠采样（约 1,006 正例 + 10,060 负例）、lr 2e-5、batch 16、epochs 3、最大长度 128 token。
- 阈值扫描：最优阈值 **0.9744**（对外显示 0.97）。
- **冻结结果**：val_v2 上 F1@0.5 = 0.6241，调优后 **F1 = 0.6871**；5 折 CV 平均 F1 **0.6234 ± 0.0240**（波动 3.9%）；弱标注标签 10 折 CV 均值 0.5487（对照）。
- 混淆矩阵（thr=0.9744）：TN=19,658 / FP=91 / FN=72 / TP=179；**GPU 推理不确定性重跑**为 TP=178/FN=73（F1 0.685，±0.002），两套矩阵已在 `results_summary.md` 显性调和。

### 5.5 多标签五类归因
- 架构：独立 sigmoid 头，五类并行判定（低音/清晰度/杂音/音量/高音），一条评论可同时命中多类。
- **冻结结果**：宏 F1 **0.6481**（epoch 4 最优）；逐类 F1：低音 0.79 / 清晰度 0.77 / 杂音 0.84 / 音量 0.84 / **高音 0.00**（样本仅 84 条且与清晰度语义重叠，已如实披露）。
- 类别分布（1,257 口径实测）：低音 205 / 清晰度 565 / 杂音 368 / 音量 379 / 高音 84；**复合差评（≥2 类）占 23.5%**（2 类 252、3 类 40、4 类 4）。

### 5.6 基线对比与显著性检验
| 方法 | 调优 F1（LLM 清洗标签） |
|---|---|
| dummy（全判正常） | 0.025 |
| TF-IDF + 逻辑回归 | 0.410 ± 0.022 |
| TF-IDF + 线性 SVM | 0.497 ± 0.017 |
| **DistilBERT（最终）** | **0.687** |

Welch t 检验：t=5.098，**p = 0.000932 < 0.05**，显著优于最强基线。
另有一组弱标注标签下的基线（dummy 0.030 / LR 0.357 / SVM 0.420）用于说明"数据提纯"的增益。

### 5.7 消融实验（3 组）
| 实验 | 调优 F1 | 结论 |
|---|---|---|
| A 无采样（全量负例） | 0.6486 | Precision 高但 Recall 仅 53%，漏掉一半差评 |
| B class_weight 平衡 | 0.6304 | 过补偿，Precision 崩至 35.5% |
| C Focal Loss | 0.6423 | 调优后不如交叉熵 |
| **最终（1:10 欠采样 + 交叉熵）** | **0.6871** | 帕累托最优 |

### 5.8 统计验证
- PR 曲线 **AUC-PR = 0.7191**。
- 学习曲线（无泄漏 bootstrap 口径，100→1,257 正例）：0.4067 / 0.5214 / 0.5099 / 0.5256 / 0.5666 / **0.6179**（1257 点为 4 次重跑均值；早期版本存在验证集泄漏，已修正并如实记录）。
- 教师一致性：小模型与 LLM 标签一致率 83.7%±2.1%（仅说明蒸馏可行性，**不作为性能证据**）。
- RoBERTa-base 2 epoch 快速探测：调优 F1 0.6169（未充分收敛，不具选型意义，结论已软化写入 `results_summary.md`）。

## 六、验证体系深化（复赛后期，D6-D8）

1. **LLM 对照实验**（固定 1,000 条子集 = val_v2 正例全集 + 749 负例采样 seed=42；同提示词、temperature=0）：
   - deepseek-chat：零样本 **0.940** / 5-shot **0.873** / 复核 **0.846**（tokens 24.9 万）
   - qwen3.7-plus（阿里云百炼 Token Plan）：零样本 **0.9149** / 5-shot **0.8937** / 复核 **0.8661**（tokens 49.1 万）
   - 小模型同子集 **0.826**
   - 口径声明：子集为留出验证集样本（小模型未见）；deepseek 的得分含"参与标签制作"的自我一致性红利；qwen 无该红利、其 0.915 为更干净信号；公开语料预训练记忆对两者均无法排除。
2. **长度分桶（tokenizer 口径）**：≤64 token F1 0.708（n=12,471）/ 65-128 token 0.749（n=3,801）/ **>128 token（被 max_len=128 截断）0.565（n=3,728，召回 54.4%）**——截断暴露面首次量化；旧字符口径被废弃并记录缺陷（11,888 条"长评"中仅 31.4% 真正超 128 token）。
3. **边界探针**：6 类边界场景 12 条定向样本，命中 7/10（委婉表达 0/2、中性比较 1/2）；发现非英文评论被静默判为正常 → 产品层改为**显式拒绝**（`is_unsupported`）。
4. **校准评估**：十箱 ECE = 0.0122，但决策区间严重过度自信（[0.8,0.9) 置信 0.854 vs 实际 0.229；[0.9,1.0) 0.975 vs 0.555）→ 全链路输出加提示"概率未经校准，仅供排序参考"（本地 Demo、线上 Demo、Agent 报告三处）。
5. **错误分类学**：FP=91 / FN=73；误报构成——"其他问题"（物流/耐用/连接/非音频产品）54.9%、整体正面 17.6%、标注存疑 13.2%、中性比较 7.7%、短文本 6.6%；漏报构成——委婉表达 37.0%、其他 31.5%、双面评价 21.9%、标注存疑 5.5%、短文本 4.1%。
6. **标注噪声人工终审**：16 条候选经队长人工复核 **15/16 确认**（93.8%，CI 71.7%-98.9%）→ 修正噪声率 **9.1%**（95% CI 5.6%-14.5%，候选集确认率下的下界估算）；样本 id69 被人工判定为"模型误报、标注正确"，如实记录。
7. **吞吐实测**：GPU 1.76 秒 / CPU 28.4 秒 per 1,000 条（含命中的多标签归因）；旧"2 分钟/99.6%"表述全部改为实测口径。
8. **时序验证**：年份分桶（覆盖 19,996/20,000）2014-2022 无单调衰减，2022 桶 F1@0.5 = 0.8049；2023 桶仅 5 正例、噪声大，已如实说明；生成月度差评率趋势图 `trend_over_time.png`。
