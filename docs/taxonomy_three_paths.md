> **缘起**：红队 `QWEN-3` 指出——五类归因体系**无外部依据**，且"高音与清晰度语义重叠"是**分类体系问题**

> **编制**：执行方（DSH）｜**日期**：2026-10-01｜**证据分级**：本地事实 / 外部已核验 / 外部惯例（未标准化）

## 〇、先把事实摆清（本地可复跑）

| 项 | 事实 | 证据 |
|---|---|---|
| 类别来源 | 五类（低音／清晰度／杂音／音量／高音）来自**语料术语表**（`label_v3.py::ISSUE_BUCKETS`）＋ **LLM 复核归类** | `label_v3.py`；`multi_label_model/issue_labels.json` |
| 外部标准 | **无**任何外部分类标准被引用或对照 | 全仓检索无 IEC／Harman／声学分类标准引用 |
| 类别规模（LLM 列） | bass 212｜clarity **569**｜noise 368｜volume 380｜**treble 124** | `labeled_llm.csv` 逐类计数 |
| 重叠证据 | 高音类测试正例仅 **10** 条；重训实验（+135 条在范围内正例，含 69 条 treble）后 **宏 F1 −0.0015、treble 不变** | `docs/b_measure_results.md`；`v2/exp_treble_*.json` |
| 语义重叠 | 高音的规则词表与清晰度高度交叉（`treble/pitch/frequency/highs/tinny/sibilance` 与 clarity 词表重叠） | `label_v3.py` 两套词表；`docs/treble_failure_analysis.md` |

**结论**：`QWEN-3` 的两条断言（无外部依据、属体系问题）**均成立**，我方此前只在附录 B 第 2 条写"语义重叠"，
**未点明这是分类体系层面的问题**——表述不足，已列入更正。

## 二、3-b 外部锚定：把类别映射到**可测频段**（**v3 方向**）

**动作**：为五类各自给出**频段/测量口径**，并与公开频响数据挂钩。

| 依据类型 | 内容 |
|---|---|
| 外部已核验 | **AutoEq**（MIT，16,301★，4.3 GB，含按型号频响派生结果）——实测可达：<https://github.com/jaakkopasanen/AutoEq> |
| 外部已核验 | **Reference Audio Analyzer** 公开耳机频响库：<https://reference-audio-analyzer.pro/hp-fr.php>（可作为第二数据源） |
| 外部**存在但未核验细节** | 耳机频响测量的**标准**（IEC 60268-7 系列）与 AES 相关测量文献——检索可见其存在（如 AES 文档库中的测量与耦合腔条款），但**我未逐条核验条款内容**，故**不得**在材料里写成"符合 IEC 60268-7" |
| 外部**惯例（非标准）** | 频段划分属**行业惯例**而非强制标准，常见口径：低频 ≈ 20–250 Hz｜中频 ≈ 250 Hz–4 kHz｜高频 ≈ 4–20 kHz。参考：[The Absolute Sound · Detailed Frequency Ranges](https://www.theabsolutesound.com/articles/detailed-frequency-ranges-of-instruments-and-vocals/) |

**映射草案（须在 v3 中定稿并标注为"本项目采用的惯例口径"）**：

| 我们的类别 | 拟对应频段 | 说明 |
|---|---|---|
| 低音 bass | 约 20–250 Hz | "浑浊/muddy"常对应低频隆起或失真 |
| 清晰度 clarity | 约 250 Hz–4 kHz | 中频，人声与主体清晰度 |
| 高音 treble | 约 4–20 kHz | 齿音/刺耳常对应 6–10 kHz 抬升 |
| 杂音 noise | 非频段（时域/失真类） | 电流声、爆音、底噪——需另立口径 |
| 音量 volume | 非频段（电平类） | 响度不足/过大——需另立口径 |

| 代价 | 2–3 天（含数据接入、映射、验证与文档） |
|---|---|
| 风险 | 中：ASIN→型号映射困难；测量数据来源多样需逐一核许可 |
| 价值 | **高**：把"主观抱怨"锚到"客观测量"，是竞品未见的维度，也是**唯一能脱离 LLM 自证的证据源** |

## 三、3-c 合并类别（treble → clarity）（**不建议**）

| 依据类型 | 内容 |
|---|---|
| 本地事实 | treble 正例 124 vs clarity 569（约 1:4.6）；合并后 clarity 变为 693 条，**treble 类消失** |
| 连锁代价 | 需**重标**（LLM 复核归类）→ **重训**多标签模型 → **全部 v2 归因数字失效**（宏 F1 0.8273／高音 0.5333）→ 主文档、附录、PPT、问答全部换代 |
| 另一条硬约束 | 我方归因模型是 **v1 冻结资产**（`multi_label_model/`，红线 1）；合并类别等于**替换冻结资产** |
| 收益 | 消除一处体系性歧义；但**不解决**"评测分辨率"（合并后该类测试正例仍约 65 条，且丢失"高音"这一对卖家最有行动价值的维度） |
| 结论 | **10/8 前不做**；即使做，也应作为 v3 的**并行实验**（保留 treble 与合并版两套，用数据决定），而不是直接替换 |
