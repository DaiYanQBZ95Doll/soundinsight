## 二、题目（三选一，我推荐第一个）

### ✅ 推荐：《面向跨境电商评论的细粒度问题归因与分诊系统设计与实现——以蓝牙耳机音质抱怨为例》

- **符合本科工程型命名范式**（"…系统设计与实现"），副标题点出领域与数据；
- 系统主线清晰：闸门预筛 → 二元判定 → 五类归因 → 三档分诊 → 报告/决策输出；
- 副标题可换为"——兼论 LLM 弱监督标签的偏差与校准"以突出特色章（若导师喜欢有研究味道的题目）。

### 备选一（更偏工程）：《基于预训练语言模型的跨境电商评论细粒度情感归因系统设计与实现》

- 更"标准"、更好过审；代价是**失去差异化**（同类题目很多）。

### 备选二（更偏应用）：《面向跨境卖家的评论归因与竞争情报生成系统设计与实现》

- 直接把输出对准**选品方向／定价策略／竞争打法**（正好补上竞赛失利的那一环）；
- 应用价值最好讲，但"归因算法"的分量会被稀释，需在论文里补足算法章。

**我的建议**：取推荐题目；把"竞争情报/决策输出"作为**系统的一个功能模块**写进去，两头的好处都拿到。

## 三、单标注者条件下，人工口径怎么写才站得住（关键设计）

只有一名标注者 → **不能报告标注者间一致性（κ）**。但可以用两个可计算的替代协议，二者都符合学术惯例：

| 协议 | 做法 | 产出指标 | 作用 |
|---|---|---|---|
| **① 重测一致性（intra-rater）** | 从已判 392 条中随机抽 100 条，**间隔 ≥7 天、盲判**（不显示上次结果与模型判定） | 自身一致率 + Cohen's κ（自身前后） | 证明"判据稳定"而非"随手判" |
| **② 人机一致性（human–LLM agreement）** | 同一子集上比对 LLM 银标与人工判定 | 一致率 + κ，并分解不一致类型 | **正好是本文主题**：量化标签偏差，且不需要第二位人 |
| ③（可选，若有同学帮忙） | 追加 1 名标注者 200 条 | 标注者间 κ | 论文里明示"条件允许时的增强" |

**论文中的诚实表述模板**：
> 受条件限制，本研究采用单标注者 + 重测一致性（κ=…）与人机一致性（κ=…）双重校验；未报告标注者间一致性，此为本研究的局限之一。

| 模块 | 现状（竞赛期已有） | 毕设需补 |

| 模型流水线 | 闸门 + 二元 + 五类多标签 + 品类/类型模型 | 模型版本管理、超参与消融配置化 |

| 文档 | README、模型卡、复现脚本 | 需求规格、概要设计、详细设计、测试报告 |

## 五、实验矩阵（按要求：本文方法 + 4 个对照）

**任务**：T1 二元（是否音质抱怨，闸门内）｜T2 五类多标签归因

| # | 方案 | 定位 | 预期成本 |
|---|---|---|---|
| 1 | 规则/词典（关键词 + 情感 + 否定） | 下界基线 | 极低 |
| 2 | TF-IDF + 线性模型（LinearSVC/LogReg，class_weight） | 传统 ML 基线 | 低 |
| 3 | BERT-base 微调 | 预训练基线 | 中 |
| 4 | LLM few-shot 提示（0/4/8-shot） | 免训练基线 | 中（API） |
| **5** | **本文方法**：闸门预筛 + DistilBERT（硬负例判别器）+ 三档分诊 | 主方法 | 低（本地推理） |

**消融**：闸门 on/off｜硬负例 on/off｜多标签 vs 五类独立二分类｜阈值 vs 三档分诊｜温度标定前后。
**标签源对照**：LLM 口径 vs 人工口径（同一评测集）→ 量化高估幅度（核心发现）。
**迁移实验**：耳机 → 音箱/条形音箱（已有音箱试点可复跑）。
**指标**：P/R/F1（Wilson 与 bootstrap 区间）、macro/micro-F1、ECE 与可靠性曲线、延迟与成本。
