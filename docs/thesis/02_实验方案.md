# 实验方案 v0.1

> **目标**：在统一数据、统一划分、统一评测协议下，比较**本文方法**与 **4 个对照方案**，并给出消融、标签源对照与跨品类迁移结果。
> **原则**（沿用竞赛期已验证的纪律）：① 先划分后训练、**先去重再划分**；② 所有对外数字带口径与区间；③ 负结果如实报告；④ 每个实验产出机器可读 JSON + 论文表格行。
> **状态**：v0.1，待题目确认后冻结（冻结后改动须升版）。

---

## 1. 数据与划分

| 项 | 设定 |
|---|---|
| 语料 | Amazon Reviews 2023（Electronics，英文），10 万条子集 |
| 闸门 | 音频词汇预筛（`audio_gate.py`）：池内 12,929 条 |
| **划分顺序** | **① 内容去重（文本级 hash）→ ② 按 hash 分层划分**（避免 X-25 的跨侧重复教训） |
| LLM 标签集 | 训练/验证/测试 = 80,000 / 10,000 / 10,000（种子冻结 42） |
| **人工金标集** | 已判 292 条（p0 100 ＋ recheck 100 ＋ xcat 92）＋ 重测 100 条（同一批判定，用于一致性而非新增标注） |
| **人工集的性质** | ⚠️ **分数分层样本**（触发档枚举 ＋ 未触发档抽样），**不是随机样本** → 估计须用分层加权 + 区间，不得直接算准确率 |
| 目标品类 | 耳机家族（headphone/earbud/headset）；迁移实验用音箱家族（speaker/soundbar/other_audio） |

---

## 2. 任务定义

- **T1 二元**：该评论是否在抱怨目标品类产品的音质/听感（闸门内）；
- **T2 五类多标签**：低音／清晰度／杂音／音量／高音；
- **T3（应用）**：三档分诊（优先处理／待复核／范围外）。

---

## 3. 对照方案（5 个）

| # | 方案 | 实现要点 | 训练成本 |
|---|---|---|---|
| **B1** | 规则/词典基线 | 音频关键词 ∧ 负面词典 ∧ 否定处理 | 无 |
| **B2** | TF-IDF + 线性模型 | word 1–2gram + char 3–5gram，LinearSVC / LogisticRegression；`class_weight=balanced`；阈值在验证集上扫描 | 分钟级 |
| **B3** | BERT-base 微调 | 同数据同划分；lr 2e-5，batch 32，epochs 3，max_len 256 | 小时级（GPU） |
| **B4** | LLM few-shot 提示 | 同一 LLM（银标同族）；0-shot / 4-shot / 8-shot；prompt 冻结留档 | API 成本 |
| **M** | **本文方法** | 闸门预筛 → DistilBERT（**硬负例判别器**）→ 三档分诊；多标签头单独训练 | 低（本地） |

> 可选 **B5**：RoBERTa-large 作为"性能上界参考"，用于效率—性能曲线（预算允许时做）。

---

## 4. 消融设计

| 编号 | 变量 | 对比 |
|---|---|---|
| A1 | 闸门预筛 | 开 / 关（关＝全量判定） |
| A2 | 硬负例 | 有 / 无（判别器 vs 底座） |
| A3 | 多标签结构 | 五类多标签 / 五类独立二分类链 |
| A4 | 分诊策略 | 二值阈值 / 三档（0.5 与 0.95） |
| A5 | 概率标定 | 原始 / 温度标定 / isotonic |

---

## 5. 标签源对照（核心）

同一人工金标集上并列计算两套口径：

| 口径 | 标签来源 | 评测集 |
|---|---|---|
| **LLM 口径** | LLM 银标 | 测试集（10,000）与人工集上的 LLM 标签 |
| **人工口径** | 人工盲判 | 人工金标 292 条（分层加权估计） |

产出：**同一模型在两套口径下的 P/R/F1 差值** → 量化"LLM 银标高估"幅度（竞赛期三次观察约 26 个百分点，本次给出正式区间）。

---

## 6. 跨品类迁移

- 训练：耳机域模型（本文方法）→ 目标域：音箱家族；
- 设置：① 零样本直接迁移；② 少量微调（2,449 条，40 分钟，沿用竞赛试点配置）；③ 与目标域从零训练对比（**补齐竞赛期缺失的 from-scratch 对照**）；
- 评测：音箱人工验收 92 条（分层）→ 人工口径 P/R。

---

## 7. 指标与统计

| 类别 | 指标 |
|---|---|
| 分类 | P / R / F1（**Wilson 区间**）、AUC-PR、macro/micro-F1（多标签） |
| 校准 | ECE、可靠性曲线、Brier |
| 分层估计 | 触发档/未触发档分层加权 + **bootstrap 95% 区间**；零命中用三倍法则给上界 |
| 配对显著性 | **McNemar 检验**（同一人工集上两方法对比）；bootstrap 差值的 95% 区间 |
| 工程 | 延迟（条/秒）、成本（$/千条）、模型体积 |

**报告规范**：任何"优于"结论必须给出配对检验与区间；区间跨 0 一律表述为"未观察到显著差异"。

## 9. 可复现与合规

- 固定：划分种子、训练种子、超参文件、库版本（torch/transformers/sklearn）、硬件；
- 冻结留档：LLM 版本与 prompt、标注手册版本、人工卡版本；
- 合规：数据来源许可声明、不含个人身份信息、仅研究用途；**公开标注子集与复现脚本**（原始评论文本以 ID + 哈希形式提供）。

## 10. 风险与降级

| 风险 | 降级方案 |
|---|---|
| B3/B4 预算或时间不足 | 只在测试集子集（2,000 条）上评估，并说明 |
| 人工集过小（292＋100） | 分层估计已给出区间；必要时只报"触发档精确率"（普查性质） |
| 迁移实验耗时长 | 只做零样本 + 少量微调两项，省去从零训练（但须在论文中标注缺失） |
| 时间线压缩到 1–2 个月 | 砍 P5 与 A5，保留 P1–P4 |
