# 实验方案 v0.1

> **目标**：在统一数据、统一划分、统一评测协议下，比较**本文方法**与 **4 个对照方案**，并给出消融、标签源对照与跨品类迁移结果。
> **原则**（沿用竞赛期已验证的纪律）：① 先划分后训练、**先去重再划分**；② 所有对外数字带口径与区间；③ 负结果如实报告；④ 每个实验产出机器可读 JSON + 论文表格行。
> **状态**：v0.1，待题目确认后冻结（冻结后改动须升版）。

---

## 1. 数据与划分

| 项 | 设定 |
|---|---|
| 语料 | Amazon Reviews 2023（Electronics，英文），10 万条子集 |
| 闸门 | 音频词汇预筛（`audio_gate.py`）：池内 12,929 条 |
| **划分顺序** | **① 内容去重（文本级 hash）→ ② 按 hash 分层划分**（避免 X-25 的跨侧重复教训） |
| LLM 标签集 | 训练/验证/测试 = 80,000 / 10,000 / 10,000（种子冻结 42） |
| **人工金标集** | 已判 292 条（p0 100 ＋ recheck 100 ＋ xcat 92）＋ 重测 100 条（同一批判定，用于一致性而非新增标注） |
| **人工集的性质** | ⚠️ **分数分层样本**（触发档枚举 ＋ 未触发档抽样），**不是随机样本** → 估计须用分层加权 + 区间，不得直接算准确率 |
| 目标品类 | 耳机家族（headphone/earbud/headset）；迁移实验用音箱家族（speaker/soundbar/other_audio） |

---

## 2. 任务定义

- **T1 二元**：该评论是否在抱怨目标品类产品的音质/听感（闸门内）；
- **T2 五类多标签**：低音／清晰度／杂音／音量／高音；
- **T3（应用）**：三档分诊（优先处理／待复核／范围外）。

---

## 3. 对照方案（5 个）

| # | 方案 | 实现要点 | 训练成本 |
|---|---|---|---|
| **B1** | 规则/词典基线 | 音频关键词 ∧ 负面词典 ∧ 否定处理 | 无 |
| **B2** | TF-IDF + 线性模型 | word 1–2gram + char 3–5gram，LinearSVC / LogisticRegression；`class_weight=balanced`；阈值在验证集上扫描 | 分钟级 |
| **B3** | BERT-base 微调 | 同数据同划分；lr 2e-5，batch 32，epochs 3，max_len 256 | 小时级（GPU） |
| **B4** | LLM few-shot 提示 | 同一 LLM（银标同族）；0-shot / 4-shot / 8-shot；prompt 冻结留档 | API 成本 |
| **M** | **本文方法** | 闸门预筛 → DistilBERT（**硬负例判别器**）→ 三档分诊；多标签头单独训练 | 低（本地） |

> 可选 **B5**：RoBERTa-large 作为"性能上界参考"，用于效率—性能曲线（预算允许时做）。

---

## 4. 消融设计

| 编号 | 变量 | 对比 |
|---|---|---|
| A1 | 闸门预筛 | 开 / 关（关＝全量判定） |
| A2 | 硬负例 | 有 / 无（判别器 vs 底座） |
| A3 | 多标签结构 | 五类多标签 / 五类独立二分类链 |
| A4 | 分诊策略 | 二值阈值 / 三档（0.5 与 0.95） |
| A5 | 概率标定 | 原始 / 温度标定 / isotonic |

## 5. 标签源对照（核心）

同一人工金标集上并列计算两套口径：

| 口径 | 标签来源 | 评测集 |
|---|---|---|
| **LLM 口径** | LLM 银标 | 测试集（10,000）与人工集上的 LLM 标签 |
| **人工口径** | 人工盲判 | 人工金标 292 条（分层加权估计） |

产出：**同一模型在两套口径下的 P/R/F1 差值** → 量化"LLM 银标高估"幅度（竞赛期三次观察约 26 个百分点，本次给出正式区间）。

---

## 6. 跨品类迁移

- 训练：耳机域模型（本文方法）→ 目标域：音箱家族；
- 设置：① 零样本直接迁移；② 少量微调（2,449 条，40 分钟，沿用竞赛试点配置）；③ 与目标域从零训练对比（**补齐竞赛期缺失的 from-scratch 对照**）；
- 评测：音箱人工验收 92 条（分层）→ 人工口径 P/R。

---

## 7. 指标与统计

| 类别 | 指标 |
|---|---|
| 分类 | P / R / F1（**Wilson 区间**）、AUC-PR、macro/micro-F1（多标签） |
| 校准 | ECE、可靠性曲线、Brier |
| 分层估计 | 触发档/未触发档分层加权 + **bootstrap 95% 区间**；零命中用三倍法则给上界 |
| 配对显著性 | **McNemar 检验**（同一人工集上两方法对比）；bootstrap 差值的 95% 区间 |
| 工程 | 延迟（条/秒）、成本（$/千条）、模型体积 |

**报告规范**：任何"优于"结论必须给出配对检验与区间；区间跨 0 一律表述为"未观察到显著差异"。

## 10. 风险与降级

| 风险 | 降级方案 |

## 11. 冻结划分已建成（2026-10-14，`v2/thesis_split.json`）

| 划分 | n | v2-LLM 正例 | 正例率 | v1 标签正例 |
|---|---|---|---|---|
| train | 10,096 | 954 | 9.45% | 1148 |
| val | 1,261 | 119 | 9.44% | 144 |
| test | 1,264 | 120 | 9.49% | 141 |

- 宇宙：**闸门内**（audio_gate）12,929 → 内容去重后 12,866 → **排除人工已判 245 条** → 12,621；
- **按内容哈希排序划分**（与行序无关，可跨文件重建复现），种子 42，分层 80/10/10；
- **自检**：三侧内容哈希交集 = 0；
- 为什么这么做：竞赛期实测（`v2_w6_split.py` 记载）标签文件重建导致行序变化后，"同一划分"
  与旧留出集重叠 **79.5%**，造成记忆性虚高。**按内容哈希划分从机制上消除该风险。**

## 12. 标签源：三方对照（论文的重要素材）

同一 12,929 条闸门内评论上存在**三套标签**：

| 标签源 | 正例数 | 说明 |
|---|---|---|
| `sound_negative`（v1 冻结） | 1,502 | 早期 RLCA 流程产出，曾用于冻结验证集 |
| `sound_negative_llm`（v2） | 1,280 | 当前 LLM 复核（高音补捞 + 中置信剔除） |
| **人工金标** | 292 条判定（1=92／0=195／?=5） | 决策方盲判，用于无偏估计与重测一致性 |

**v1 与 v2 的重叠只有 778 条**（仅 v1 有 724、仅 v2 有 502）——两套自动标签在同一批文本上分歧巨大。
这为论文提供了现成的三方比较：**同一模型分别在 v1／v2／人工口径下的指标差异**，
可用于量化"标签源选择对结论的影响"，与竞赛期发现的"LLM 口径系统性高估"互为印证。

## 13. P1 阶段结果（已完成）

见 `docs/thesis/tables/exp_results.md`（脚本生成，禁止手抄）。当前：

- **B1 规则/词典**：P 17.6%、R 75.8%、
  F1 28.5%（AUC-PR 0.219）→ 规则能覆盖多数正例但精度极低；
- **B2 TF-IDF+LogReg**：P 62.3%、R 63.3%、
  F1 62.8%（AUC-PR 0.645、ECE 0.084）；
- **McNemar（B1 vs B2）**：χ²=279.9、**p<0.0001** → B2 显著更优。

下一阶段（P2）：在**本冻结划分**上重训本文方法（竞赛期的判别器是在旧划分上训练的，
直接拿来评估会与 test 侧重叠 → 必须重训），并做消融 A1–A5。

## 14. P2 阶段结果（留出集）与**功效问题**（重要，如实记录）

### 14.1 留出集（n=1264，正例 120，v2-LLM 口径）

| 方法 | P | R | F1 | AUC-PR | ECE |
|---|---|---|---|---|---|
| B1 规则/词典 | 17.6% | 75.8% | 28.5% | 0.219 | 0.197 |
| B2 TF-IDF+LogReg | 62.3% | 63.3% | 62.8% | 0.645 | 0.084 |
| **M 本文方法（闸门＋硬负例）** | **68.6%** | **69.2%** | **68.9%** | **0.718** | **0.045** |

### 14.2 ⚠️ **B2 与 M 的差异在本留出集上不显著**

| 对比 | 只 A 对 | 只 B 对 | χ²(校正) | p |
|---|---|---|---|---|
| B1 vs B2 | 55 | 421 | 279.88 | **< 0.0001** |
| **B2 vs M** | 35 | 50 | 2.31 | **0.129（不显著）** |

**解释（必须写进论文）**：留出集仅 120 个正例，配对检验功效不足；F1 的点估计差（62.8% → 68.9%）
**不能据此宣称显著更优**。这不是"方法无差"，而是"证据不足以断言"。

### 14.3 解决路径：K 折交叉验证（提高功效）

用 5 折 CV 为**每个**闸门内条目取得袋外预测 → 配对比较从 1,264 条提升到 **12,621 条（正例 1,193）**。

- **B2 的 CV-OOF 结果**：P 62.4%／R 57.8%／**F1 60.0%**
  （TP690/FP416/FN503，耗时 28s）；
- **M 的 CV** 需要 5 次训练（每折约 17 分钟，合计约 85 分钟），将在下一阶段完成；
- 论文中**同时报告留出集与 CV 两套结果**：留出集为预注册主口径，CV 用于配对检验的功效补足。

### 14.4 消融结果

| 消融 | 结果 |
|---|---|
| **A1 闸门预筛** | 闸门外抽样 2,000 条触发率 0.1% → 外推 FP ≈ 131 条；**精确率 开闸门 68.6% vs 不开 33.0%**（闸门使精确率翻倍） |
| **A5 温度标定** | val 拟合 T=1.85 → 测试集 **ECE 0.0448 → 0.0203**、Brier 0.0506 → 0.0454 |
| **A2 硬负例** | 无硬负例 F1 68.4%（P 70.2／R 66.7，AUC-PR 0.685）vs 有硬负例 F1 68.9%（AUC-PR 0.718）；**McNemar χ²=0.000、p=1.0000 → 阈值 0.5 处无任何可测差异**（23 vs 22 对不一致）；仅排序指标 AUC-PR 略有高低 → **竞赛期采用的硬负例方案在本划分上未复现收益**（如实报告） |
| A3/A4 | 待做（多标签结构、分诊阈值） |

**A1 的关键事实**：全部 1,280 个 LLM 正例**都在闸门内**（闸门外正例 = 0），故闸门外触发全为误报——
这既解释了闸门的价值，也说明"闸门内评估"是任务定义的自然边界。
