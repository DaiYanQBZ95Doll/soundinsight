## 三、模型与指标

### 3.1 ⚠️ 三代数值**不可排成上升线**（2026-10-01 更正）

**旧版此表把 0.37 → 0.6871 → 0.7220 排成递增，制造了可比性错觉**——红队指出这恰好违反本文件 §十二
自己写的禁令。三个数**不在同一坐标系**：语料不同（5,000 vs 100,000）、验证集不同、正例数不同
（13 / 251 / 128）、阈值规则不同。**现改为分列陈述，并补上同基准对照。**

| 项 | 初赛 | 复赛（v1） | 决赛（v2） |
|---|---|---|---|
| 语料 | 5,000 | 100,000 | 100,000 |
| 验证集 | 1,000 条（13 正例） | `val_v2` 20,000（251 正例） | `val_v3_test` 10,000（**128 正例**） |
| 该集上报告值 | F1 **0.37**（阈值 0.0009，自述不可用） | F1@调优(0.9744) **0.6871** | F1@调优(0.6) **0.7220** |
| 该值的可信状态 | 正例过少、波动极大 | **当时划分内有效，现已不可复现**（文件重建） | 构造上干净（训练/测试按当前文件划分互斥） |

### 3.2 同基准对照（2026-10-01 新增实验，回应红队刺 2/3）

把 v1 与 v2 **都放到 `val_v3_test`** 上，阈值按**同一规则**在 `val_v3_tune` 上选；
F1 的 95% 区间由 2,000 次 bootstrap 得到。

| 模型 | 阈值 | F1 | 95% CI | P | R |
|---|---|---|---|---|---|
| v1（产品在用） | 自身档 0.97 | 0.8043 | 0.7490–0.8526 | 0.750 | 0.867 |
| v1 | tune 选 0.95 | **0.7759** | 0.7213–0.8261 | 0.678 | 0.906 |
| v1 | 固定 0.5 | 0.6893 | 0.6282–0.7426 | 0.540 | 0.953 |
| **v2（决赛候选）** | 自身档/tune 选 0.60 | **0.7220** | 0.6547–0.7857 | 0.770 | 0.680 |
| v2 | 固定 0.5 | 0.7206 | 0.6547–0.7837 | 0.748 | 0.695 |
| v2 ＋ 1:10 欠采样（实验） | tune 选 0.90 | 0.6273 | 0.5574–0.6957 | 0.594 | 0.664 |

**三条结论（必须连读）**：

1. **没有证据表明 v2 优于 v1**：同规则选阈值下 v1 = **0.7759**、v2 = **0.7220**，
   点估计**偏向 v1**；两者 CI **重叠**（0.721–0.826 vs 0.655–0.786）→ **统计上不可分辨**；
2. **且 v1 的数字另有疑点**：v1 的训练文件是**已重建前**的版本（现不在仓库），
   对称推理——已实测 `val_v2` 有 **79.5%** 落在当前训练划分内，则当前留出集（含 `val_v3_test`）
   很可能有约 **80%** 落在 v1 的早期训练集内（**镜像泄漏**）。**本仓库无法验证该假说**
   （早期文件缺失）。故 v1 的 0.7759/0.8043 **不可采信为干净对照**；
3. **唯一较干净的比较**是固定 0.5 档：v2 **0.7206** vs v1 **0.6893**——
   但即便 v1 被镜像泄漏抬高，该比较仍**不对称**，故只能作为"**不反对 v2 至少不差**"的弱证据。

> **因此本文件撤回此前"v1→v2 是提升"的任何暗示**：正确的说法是
> **「两代数字不可比；同基准下差异不可分辨，点估计偏向 v1，而 v1 自身受镜像泄漏嫌疑」**。
> 另外补充：1:10 欠采样实验（复刻 v1 配方）得 **0.6273**，说明**配方差异也不是 v2 得分较低的解释**。

### 3.3 归因数字的来源必须点明（回应红队刺 4）

此前表把"归因宏 F1 0.6481 → 0.8273、高音 0.00 → 0.5333"列为进步。实测（`same_basis_compare.py`）显示：

| 同一模型（**v1 冻结的多标签归因模型**，权重未变） | 宏 F1 | 高音 F1 |
|---|---|---|
| 在 `val_v3_test` 上、**统一 0.5** 阈值 | **0.7180** | **0.0000** |
| 在 `val_v3_test` 上、**逐类阈值**（tune 选：0.25/0.25/0.35/0.60/0.25） | **0.8273** | **0.5333** |

**结论：0.6481→0.8273 与 0.00→0.5333 的跳变主要是「阈值选择 + 换了测试集」造成的，
不是模型能力提升**——因为归因模型的权重**根本没换**（仍是 v1 冻结权重）。
且两侧标签均由 LLM 生成（**同源，未校准**），该组数字须始终带此限定词。

### 3.2 ⚠️ 最容易被误读的一点：**决赛并未替换产品里的模型**

| 问题 | 事实 |
|---|---|
| 决赛包里的产品用什么模型？ | **仍是 v1 冻结权重**——`config.json` 指向 `sound_model/` + `multi_label_model/`，`max_len: 128` |
| 那 v2 是什么？ | **候选模型 + 证据层**：用于回答"换到 256 窗口能到多少"，权重按 **hash + 训练命令**登记（**不入包**，本机 255 MB，包内不含 `safetensors`） |
| 为什么这么做？ | 交付风险最小化：v1 是已提交、已验证、已部署的权重；v2 是改进证据，采纳与否属决策范围 |
| 材料层做了什么？ | **v1 → v2 口径换代**：143 处 v1 数字加 `[v1]` 标注、5 份文件插入 v2 现状块、核对器待处理 **0 行**（M0） |

> 因此对外表述必须成对出现：**产品跑 v1（0.6871），决赛证据是 v2（0.7220）**，
> 两者样本集不同、**不可直比**——这一句在 README、主文档 5.2/附录 A 逐字一致（M0b 机械检查）。

## 八、叙事与定位的迁移

| 阶段 | 叙事重心 | 对外一句话 |
|---|---|---|
| 初赛 | 痛点与创意 | "卖家的音质差评没人系统梳理，我们来做" |
| 复赛 | 实现与指标 | "10 万条语料、RLCA 标注、DistilBERT 0.687、已上线" |
| 决赛 | **可信度与边界** | "指标是 0.7220（v2 口径，**且不主张优于 v1**）；**同时我们知道自己在哪不灵**——长文本 68.3%、最弱类高音 **0.5333（逐类阈值口径；统一 0.5 时为 0.0000）**、覆盖 **实测只到 52.0%（LLM 口径，未经人工校准）**，这些都写在附录 B 里" |

**叙事上最大的转折（已按红队刺 5 更正措辞）**：决赛把「公布自己的盲区」变成了资产。
但必须去掉「实测」一词带来的确定感——覆盖数字是**LLM 口径自报，未经独立校准**（唯一的独立证人 G-1 人工金标**尚未执行**）。准确表述：
**「我们量了自己的盲区，但量它的人与标注数据的人是同一个 LLM」**。

**并且必须点破一处此前被排版掩盖的含义（红队刺 6）**：
正例数 1,280「未扩」与「闸门外还有 ≈1,161 条真阳性未入库」两件事连起来读 =
**训练集漏掉了约 48% 的在范围内正例**（1,161 / (1,280+1,161)）——
即当前模型是在**一个只覆盖约一半正例总体**的标签集上训练的。
（限定：这 1,161 是 LLM 口径外推、未经人工确认，且尚未并入训练/评估。）
