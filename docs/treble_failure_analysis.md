# 高音（Treble）归因失效机制诊断（treble_failure_analysis.md）

> 结论前置：**高音 F1 = 0 的主因不是"学不会"，而是"从不触发"**——该分类头在 0.5 阈值下对验证划分 252 条样本的预测概率最大仅 0.3332，被判为正的样本数为 0。因此 TP=0、FP=0、FN=13，F1 因"零预测"归零，而不是"预测错误"。
>
> 复算脚本：`diagnose_treble.py`（只读诊断：不改模型、不改标签、不重训）。本文件全部数字由该脚本实测输出，并复现了冻结口径（宏 F1 0.6481）。

## 一、诊断口径

| 项 | 值 |
|---|---|
| 模型 | 冻结的 `multi_label_model`（DistilBERT + 5 个 sigmoid 头） |
| 标签版本 | `labeled_llm_before_treble.csv`（**1,257 正例 / 高音 84 条**，与冻结多标签模型对应） |
| 划分 | 复现训练脚本逻辑：`train_test_split(test_size=0.2, random_state=42, stratify=Y.argmax(axis=1))` → 训练 1,005 / 验证 252 |
| 判定阈值 | 0.5（与其他类别一致） |

## 二、核心证据

### 2.1 逐类指标（验证划分，冻结模型）

| 类别 | F1 | TP | FP | FN | 预测为正 |
|---|---|---|---|---|---|
| 低音 | 0.7945 | 29 | 3 | 12 | 32 |
| 清晰度 | 0.7714 | 81 | 13 | 35 | 94 |
| 杂音 | 0.8392 | 60 | 7 | 16 | 67 |
| 音量 | 0.8356 | 61 | 11 | 13 | 72 |
| **高音** | **0.0000** | **0** | **0** | **13** | **0** |

- 五类宏 F1 = **0.6481**（与 `results_summary.md` 一致）；**剔除高音后四类宏 F1 = 0.8102**。
  → 高音单独把宏 F1 拉低 **0.162**（相对降幅约 20%）。

### 2.2 高音概率分布（验证划分 252 条）

| 统计量 | 值 |
|---|---|
| 中位数 | 0.0508 |
| P90 / P95 / P99 | 0.1581 / 0.2114 / 0.3083 |
| 最大值 | **0.3332** |
| 概率 ≥0.5 的样本 | **0 条** |
| 13 条高音正例 | 均值 0.1877，最大 0.3211，其中 ≥0.5 的 0 条 |

结论：该分类头输出被系统性压低（整体偏置向 0），在与其他类别相同的 0.5 阈值下**永不触发**。

### 2.3 只调阈值能不能救（阈值扫描）

| 阈值 | 预测为正 | TP | FP | FN | F1 |
|---|---|---|---|---|---|
| 0.50 | 0 | 0 | 0 | 13 | 0.0000 |
| 0.40 | 0 | 0 | 0 | 13 | 0.0000 |
| 0.30 | 4 | 2 | 2 | 11 | 0.2353 |
| 0.25 | 7 | 3 | 4 | 10 | 0.3000 |
| **0.20** | 18 | 8 | 10 | 5 | **0.5161** |
| 0.15 | 27 | 8 | 19 | 5 | 0.4000 |
| 0.10 | 39 | 10 | 29 | 3 | 0.3846 |

**关键推论**：高音头并非"无信号"——阈值降到 0.20 时 F1 可达 **0.5161**（TP 8、FP 10）。也就是说它携带了有效信号，但**校准严重偏低 + 阈值不匹配**，在统一 0.5 阈值下被完全掩埋。即便如此，0.52 仍显著低于其他四类（0.77-0.84），说明样本量与标签一致性仍是瓶颈。

### 2.4 标签侧证据（1,257 口径全量）

| 现象 | 数字 |
|---|---|
| 高音正例 | 84 条（占正例 6.7%） |
| 高音正例中同时标了"清晰度" | **34 条（40.5%）** |
| 清晰度正例中同时标了"高音" | 34 条（565 条的 6.0%） |
| 正文含高音关键词（treble / high-end / shrill / harsh / piercing / tinny / sibilant）的评论 | **206 条** |
| 其中被标为高音 | **77 条** → **漏标 129 条（62.6%）** |
| 标为高音但正文含清晰度关键词 | 26 / 84（31.0%） |

结论：**高音标签既稀疏又不一致**——带明确高音关键词的评论里约 62.6% 未被标注为高音（LLM 复核时多归入"清晰度"或未标注），模型能学到的"高音"概念因此边界模糊。

## 三、失效原因排序（按证据强度）

1. **校准偏低 + 统一阈值**（直接原因，证据最硬）：概率上界 0.33 < 阈值 0.5 → 零预测 → F1=0。降到 0.20 可得 0.5161。
2. **训练信号被压制**（结构性原因）：训练正例 71 条 vs 清晰度 449 条；多标签训练**未做类别加权**（`train_multilabel.py` 使用普通 BCE，无 `pos_weight`）；5 个头共享同一编码器，稀少类梯度被淹没。验证划分仅有 13 条高音正例，指标本身方差极大。
3. **标签语义重叠与漏标**（数据原因）：84 条高音中 40.5% 同时是清晰度；关键词命中的 206 条里 129 条没被标高音。用这样的标签训练，模型难以学出"高音"的独立决策边界。
4. **分层方式加剧稀少**（次要）：`stratify=Y.argmax(axis=1)` 按"首个命中类别"分层，高音在列尾，只有"仅高音"的样本才单独成层，导致验证划分中高音正例进一步稀少（13 条）。
5. **基座与领域**（影响最小）：DistilBERT 英文通用基座对声学词汇的表征有限，但其他四类在同样基座下达到 0.77-0.84，说明基座不是主因。

## 四、可修与不可修（如实）

**当前不可做**：任何修复都需要动多标签模型（重训）或改标签，而模型与训练脚本处于**红线冻结**状态，因此本轮不修，只做诊断与记录。

**将来若解冻，按性价比排序的修复方案**：
1. **逐类阈值**：为高音单独设 0.20（预期 F1 ≈ 0.52），成本最低、不需要重训，但需在验证集上重新确定阈值并披露 FP 上升（10 条误报）。
2. **类别加权损失**：为 5 个头加 `pos_weight`（如按负正比例），预计提升稀少类召回；消融 B 曾在二分类上验证过 class_weight 的"过补偿"风险，多标签侧需要重新调参。
3. **标签重定义**：把"刺耳/尖利"明确归入"清晰度"或把高音定义为包含尖锐度（v4 §9.2 已列为后续工作），可消除 40.5% 的重叠与 62.6% 的漏标。
4. **定向补样 + 重训**：工作集已把高音从 84 补到 124（+40），但**冻结模型未用这 124 版本重训**，故当前 F1=0 是 84 标签版本的性质；将来重训时应用新标签并重新划分（并改用 multilabel 分层策略，如 iterative stratification）。

## 五、对外表述建议（答辩/文档口径）

- 可以说：**"高音类的失效已定位为校准偏低导致的零触发，而非模型无能力——把阈值降到 0.20 即可恢复 F1 0.52；其根因是样本仅 84 条且与清晰度标签重叠 40.5%、关键词覆盖漏标 62.6%。"**
- 不要说：**"高音样本少所以做不了"**——这把可修问题说成了不可修，也与本次诊断结论不符。
- 不要声称已修复：本轮只做诊断，模型仍冻结（F1=0 未变）。
