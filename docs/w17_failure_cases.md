# W17 失败案例附录（每条附发生率分母）

> **DoD（冻结清单 §二 W17）**：≥10 条失败案例，**每条附发生率分母与比例**；孤立的失败是噪音，
> 带频率的失败才是诚实。对外结论 100% 带置信度档位与建议动作。
> **数据来源**：冻结 v1 模型在 `val_v2`（20,000 条，正例 251）上的既有预测 `val_preds_dump.csv`，
> 元数据经 `review_meta_v2.csv`（P0-3 产物）按文本连接。整体：**TP 178 / FP 91 / FN 73 / TN 19,654**。
> **生成**：2026-09-30（执行方）｜原始统计：`v2/w17_failure_stats.json`

## 一、按失败类型的案例（含分母）

### 案例 1：长文本漏报（>128 字符桶）
- **现象**：1,036 字符的耳机听感逐小时记录（Sennheiser HD 598），模型概率 **0.0006**，判为正常。
- **分母与比例**：>128 字符桶 **65/211 = 30.8%** 的正例被漏（该桶 11,888 条、占全量 59.5%）。
- **根因**：v1 训练/推理窗口 `max_len=128` token，超出部分被截断，关键差评句常在后半段。
- **置信度档**：低（概率远低于任一卷积档）｜**修复状态**：**修复中**（W1 四方案对比，进行中）
- **对照**：同桶模型侧另有 73 条误报（负例率 0.63%），长文本整体更难。

### 案例 2：中长文本漏报（65–128 字符桶）
- **分母与比例**：**5/26 = 19.2%** 正例被漏（该桶 3,301 条）。
- **根因**：多因素混杂（委婉表达 + 与其它问题并列），非长度问题。
- **修复状态**：不可单独修复，随 W1 与标签改进缓解。

### 案例 3：极短文本漏报（≤64 字符桶）
- **现象**：`"love it"`（7 字符，1★）概率 0.0004 判为正常。
- **分母与比例**：**3/14 = 21.4%** 正例被漏（该桶 4,807 条）。
- **根因**：**信息量不足**——文本本身无音质线索，仅凭星级无法判定；属数据固有边界。
- **修复状态**：**不可修**（诚实披露；建议产品侧对极短文本降低置信度并提示人工复核）。

### 案例 4：跨品类 / 非音频评论误报
- **现象**：三条高置信误报——卫星接收机评论（prob 0.9889）、键盘清洁泥（0.9887）、蓝牙鼠标适配器（0.9896）。
- **分母与比例**：>128 字符桶误报 **73/11,815 = 0.62%**（负例率）；全量误报 **91/19,745 = 0.46%**。
- **根因**：Electronics 类目含大量非音频商品；文本中出现 sound/audio/connection 等词即被触发。
- **置信度档**：**高**（模型高置信但错误）——属"高置信错误"，最危险的一类
- **修复状态**：**可缓解未修**：① 产品侧增加"非音频品类"前置判断（W9 非音频子集误报率为其量化）；② 关键词否定约束。

### 案例 5：5★ 评论误报
- **分母与比例**：**20/13,098 = 0.15%**（5★ 档负例率，全档最低）。
- **含义**：五星好评中的误报**量级很小**；与"三星 41.5% 隐藏差评"形成对照——
  在现有标签体系下，**隐藏差评主要集中在 1–3★**，4★/5★ 近 0 是"管线未纳入候选"的结果，
  不能据此断言四五星无隐藏差评（W4 待测）。

### 案例 6：2★ 档误报率最高
- **分母与比例**：**12/780 = 1.54%**（2★ 负例率），高于 1★ 0.66%、3★ 0.83%、4★ 1.25%。
- **根因**：2★ 评论常为"部分满意 + 部分不满"的混合体，边界模糊。

### 案例 7：未验证购买评论的误报率更高
- **分母与比例**：未验证 **24/4,154 = 0.58%** vs 已验证 **67/15,591 = 0.43%**（**1.35×**）。
- **含义**：`verified_purchase` 是有效的噪声代理；仅保留已验证评论后整体 **F1@0.9744 0.6871 → 0.7034**（W14）。
- **修复状态**：**已量化，建议产品侧提供该过滤开关**。

### 案例 8：高音类别零触发（系统性失效）
- **现象**：v1 多标签模型对 84 条含高音标签的样本**最高概率 0.3332 < 0.5**，TP=0、FP=0、FN=13。
- **分母与比例**：该类别在 1,280 条正例中占 **124 条（9.7%）**；关键词漏检率 **62.6%**。
- **旁证**：本附录的漏报类别分布中"高音"仅 **2 条**（杂音 29 / 清晰度 24 / 音量 23 / 低音 6 / 高音 2）——
  说明该类别几乎不产生任何输出，问题不是"漏得多"而是"从不触发"。
- **置信度档**：不适用（无输出）｜**修复状态**：**未启动**（方案 C 已选；W3 处理）

### 案例 9：归因阈值未校准 → "判负但归因空白"（历史上出现过）
- **现象**：v1 早期版本对 98.9% 的评论判为音质差评，但五类归因全部为空。
- **根因**：多标签输出未做逐类阈值校准，统一 0.5 与实际分布不匹配。
- **修复状态**：**处理中**（W2：阈值只在 `val_v3_tune` 上选、只在 `val_v3_test` 上报）

### 案例 10：标注噪声（不可修，只能披露）
- **分母与比例**：人工终审 **15/16**，噪声率 **9.1%**（Wilson 95% CI 5.6–14.5%）。
- **含义**：约每 11 条正例中有 1 条标签可疑；这构成任何 F1 的**上限约束**。
- **修复状态**：**不可修**（需第二标注者，缺憾 A2-11；代理指标终审确认率 93.8%）

### 案例 11：非英文评论被显式拒绝（覆盖缺口）
- **现象**：非英文评论不进入模型，按"显式拒绝并计数"处理（代码行为；v4 §9.1 的旧表述已列为勘误）。
- **分母与比例**：本语料为英文站点数据，非英文占比低；**跨语种覆盖为 0%**。
- **修复状态**：**未做**（Ring B 排除；路线 C 中文评测集规格已在清单 B2-20）

### 案例 12：代际标签漂移的核查（**本条同时更正一处此前的错误结论**）
- **核查方法**：把 73 条漏报、91 条误报的文本逐一连到**现行**标签集（`labeled_llm.csv`）比对。
- **结果**：漏报 **72/73 在现行标签下仍是正例**（真实漏检）；误报 **91/91 仍是负例**（真实误报）。
- **更正留痕**：执行方当日曾据一处取反错误得出"71/73 属标签漂移"的结论，经直接测量推翻并修正
  （见 `v2_w6_split.py` docstring 的更正说明）。
- **附带事实**：同一批 20,000 条文本上，v1 冻结标签与现行标签**仅 6 条不一致、4 条缺失**（99.95% 稳定）。

### 案例 13：GPU 重跑的非确定性（已披露）
- **现象**：冻结混淆矩阵 **TP=179**，GPU 重跑调和为 **TP=178**（FN 由 72 → 73）。
- **分母与比例**：影响 1/251 正例（0.4%）。
- **修复状态**：**已披露**（`results_summary.md` 并存两行并说明；审计含该调和行检查）

## 三、这些案例在材料中的用法（建议）

1. **不要隐藏**：本附录整体对外，是"带频率的失败"的实证；
2. **与修复进度对照引用**：案例 1（长文本）在 W1 完成后须更新为"修复前后对比"；
   案例 8（高音）在 W3 完成后同上；
3. **不得把"未修"写成"已修"**：闸门第 (6) 条要求未修短板仍在局限章节；
4. **高置信错误单列**：案例 4 属最危险类型，须在产品说明中给出缓解措施（品类前置判断/否定词约束）。
