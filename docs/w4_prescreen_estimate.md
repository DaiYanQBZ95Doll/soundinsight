## 必须同时声明的边界（不可省）

1. **这是代理口径**：模型在正例上的 P≈77.0%、R≈68.0%（v2 调优档），因此「模型判正」**既含误报也含漏报**，不能当作「新增正例数」对外宣称；
2. **它不能替代 LLM 复核**：W4 复核段仍待凭证（`v2_w4_mine.py --review`），复核完成后用 `v2_w4_estimate.py` 出正式估计；
3. **它的用途**：① 凭证到位前给出量级与分层结构；② 与 LLM 复核结果对照，可量化「模型 vs LLM」在四五星子集上的一致性（一个额外的方法学产出）。

## 产出率含义（**这一节是本节最重要的结论**）

预筛结果**远低于直觉预期**：全池 12,744 条四五星候选中，模型仅判正 **60 条（0.5%）**；
分层样本层为 **1/293 = 0.3%**（Wilson 95% CI 0.1–1.9%）。

把它换算成"预期新增正例"的三种口径：

| 口径 | 数值 | 说明 |
|---|---|---|
| 直推命中（原始） | **60 条** | 模型判正，未做校正 |
| 按精确率折算为真 | ≈ **46 条** | ×P(77.0%)，即"其中约多少确实是音质差评" |
| **召回校正上界** | ≤ **88 条** | ÷R(68.0%)，即"即使所有漏报都补上"的天花板 |

**结论：四五星开采的预期新增正例量级是"几十条"，而不是"上千条"。**
原因很直接：**四五星评论提到音质时，绝大多数是在夸**（我们的候选规则只要求"含音质关键词且无正面极性强表述"，
无法区分"bass is great"与"bass is muddy"）；真正被漏掉的音质差评集中在**三星**（实测 41.5%），
而三星补漏在 v1 阶段已经做完（补漏 479 条）。

### 对 W4b 叙事的修正（如实）

- 此前记录"候选 12,744 条 = 预期 ≈300 的 **42 倍**、触发分层抽样"——**该判断仍然正确**（抽样是为了控制成本）；
- 但**不能**由此推出"池里有大量隐藏正例"：预筛显示产出率不到 1%，
  故 **293 条分层样本的 LLM 复核**足以给出可信的产出率与上限（成本约 0.01 美元）；
- 若决策方希望进一步确证，可把复核扩大到全部 12,744 条（**成本约 0.38 美元**，见 `docs/w4_mining_estimate.md`）。

### 与 LLM 复核的关系

本页是**代理口径**（模型，P 77.0%／R 68.0%）。凭证到位后跑 `v2_w4_mine.py --review`：
- 若 LLM 复核的命中率与模型同量级（<1%），则上述结论成立，W4 记为"低产出率、已量化"；
- 若 LLM 命中率显著更高（例如 >5%），说明**模型在这类"表面正面、实为抱怨"的文本上有系统性漏检**——
  那本身是一个有价值的方法学发现（模型的能力边界），会一并如实记录。
